# Баллада: любовь восторжествовала — сценарий монтажной склейки 3×10 с

**Дата:** 2026-08-12. Реализация шага 2 «Монтажная склейка» из `PROMPT-FORMAT-PLAN.md`,
сценарий на тридцать секунд написан целиком заранее, как требует раздел 3.1 руководства.

## Сюжет

| ролик | промпт | содержание |
|---|---|---|
| 1 | `prompts/greek-official.txt` (уже посчитан очередью queue27) | грек и амазонка сходятся в бою на пасмурном хребте; финал — сцепка меча и копья, широкий силуэт |
| 2 | `prompts/ballad-2-almost-victory.txt` | грек ломает сцепку, вырывает инициативу, она падает; он заносит меч — и замирает, встретив её взгляд; меч медленно опускается |
| 3 | `prompts/ballad-3-love-triumphs.txt` | он роняет меч, протягивает руку; она отбрасывает копьё, он поднимает её; объятие и поцелуй, отъезд камеры на широкий план: двое обнимаются, оружие в пыли |

Ролик 1 не пересчитываем: `greek-official` из `26-формат` уже кончается нужной сценой.
Это экономит 76 минут; если сравнение по шагу 0 покажет, что прогон плох, ролик 1
переписывается отдельно.

Речи нет намеренно: эксперимент «речь» по плану отдельный, здесь проверяется только склейка.
Музыка развивается через ролики как баллада: барабаны боя → замедление и одинокий аккорд →
арфа, струнные и фортепиано.

## Механика склейки

Кадр-условие берётся **из предпоследней секунды, а не самый последний кадр** — финалы смазаны
движением (зафиксировано в плане как переменная на потом). Ролики 2 и 3 нарочно кончаются
почти статичными позами, чтобы их финальные кадры годились как условие.

```bash
# кадр для ролика 2: предпоследняя секунда ролика 1
ffmpeg -sseof -1.5 -i h3-greek-official-896x576.mp4 -frames:v 1 ballad-key-1to2.png

# кадр для ролика 3: предпоследняя секунда ролика 2
ffmpeg -sseof -1.5 -i h3-ballad-2-896x576.mp4 -frames:v 1 ballad-key-2to3.png
```

Запуск (рецепт тот же, что во всей серии 26: 8 бит, 8 шагов, LoRA 1.0, таблица l100):

```bash
h3 generate --prompt-file prompts/ballad-2-almost-victory.txt --mode i2va \
  --image ballad-key-1to2.png \
  --checkpoint ~/models/h3-8bit-full --width 896 --height 576 --duration 10 --steps 8 \
  --seed 20260821 --tag ballad-2 \
  --adaln-cache ~/models/turbo/adaln_8_l100.safetensors \
  --turbo-lora ~/models/turbo/minimax_h3_turbo_v4_step600_ema.safetensors --turbo-strength 1.0
```

Ролик 3 — так же, с `ballad-key-2to3.png` и `ballad-3-love-triumphs.txt`.

Сборка: `ffmpeg -f concat` по списку из трёх mp4 (кодеки совпадают — конвертация не нужна),
звук стыкуется как есть; про плавность музыкальных стыков решать после первого прогона.

## Что проверяет эксперимент

1. Держится ли идентичность двух персонажей через две I2VA-склейки (лица, телосложение, свет).
2. Работает ли дословная первая строка I2VA из руководства на нашем 8-битном чекпоинте.
3. Переживает ли смысловая дуга («бой → пощада → любовь») разрезку на три независимых прогона.

Открытые переменные, зафиксированные заранее: выбор кадра из предпоследней секунды (а не
последней) и сид 20260821 у всех трёх роликов.
