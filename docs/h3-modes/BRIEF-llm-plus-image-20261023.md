## 2. Пробы (GPU)

Для каждого профиля LLM, который по таблице влезает рядом (начать с самого малого контекста, затем 32k, затем
больше, пока влезает): поднять LLM, затем ComfyUI-копию, и
- 5 картинок Krea 2 1344×768 и 5 — Z-Image 1344×768 при **простаивающей** LLM: время, пик памяти устройства
  (nvidia-smi с шагом 0,5 с — не `torch.cuda.max_memory_allocated`);
- те же картинки при **одновременном** запросе к LLM (типовой запрос «Сценариста»: системный промпт + идея →
  JSON из 2 сцен, ~1,5 тыс. токенов вход, ~800 выход) — время обеих сторон, нет ли OOM / вылета;
- 2 МП (1920×1088) у Krea при LLM — влезает ли;
- LLM после картинки: префилл и генерация не деградировали?
Без OOM-пробы на пределе, которые роняют драйвер: если до предела < 2 ГБ — не запускать, записать расчёт.
