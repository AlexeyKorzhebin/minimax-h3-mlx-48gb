# Ресерч: готовые студии генерации видео/картинок, похожие на наш замысел (09.10.2026)

Контекст: `docs/superpowers/specs/2026-10-09-studio-vision.md` и `docs/superpowers/specs/vision-review/SUMMARY.md`.
Мы хотим не изобретать велосипед. Найден AI Movie Studio 2 (github.com/Heroesjouney/AIMovieStudiov2):
FastAPI + Next.js поверх ComfyUI, H3/Krea 2/Z-Image/LTX/Wan, сцены с референсами, продолжение от
последнего кадра, таймлайн; нет LLM-сценариста и телефона, AGPL, WIP. Ищем похожее, но мощнее/зрелее.

## Критерии (оценивай каждый найденный вариант)
1. Self-hosted, локально (одна CUDA-карта 64 ГБ на Linux + Mac для разработки). Облачные-только — отдельным списком «для идей».
2. Исполнитель: ComfyUI (или свой, но тогда какой) — можно ли подключить свой ComfyUI/sglang по адресу.
3. Слой проекта: проект → сценарий → сцены → дубли → сборка/таймлайн; персонажи/референсы с консистентностью; продолжение от последнего кадра.
4. Модели: MiniMax H3, Krea 2, Z-Image, LTX 2.x, Wan 2.x; LoRA.
5. LLM: сценарист/раскадровка через LLM (OpenAI-совместимый провайдер), Vision-оценка.
6. Интеграции: API, MCP-сервер, агентные хосты (Hermes, OpenClaw, Claude), мобильный доступ.
7. Зрелость: звёзды, последний коммит/релиз (дата!), число контрибьюторов, лицензия, документация.
8. Насколько можно взять целиком / как основу / только куски.

Факты проверяй по первоисточнику (GitHub-страница, релизы). Дату последнего коммита указывай.
Не путай мёртвые проекты 2024 года с живыми 2026.
