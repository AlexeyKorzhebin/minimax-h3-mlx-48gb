## Что понравилось
- Провайдеры как один файл с чистыми типами; ИИ-мастер сам пишет провайдер по документации (промпт встроен).
- Свой LLM по OpenAI-адресу с автозагрузкой списка моделей, ключ можно пустым.
- Русский интерфейс из коробки, MIT, Docker за 6 минут, MCP и A2A из коробки.
- Холст: прозрачные связи, кадр из видео в картинку-узел одним кликом.

## Что мешает
- Холст-центричная модель не совпадает с нашим «сцена - дубли - сборка», сборки ролика нет.
- ComfyUI, Draw Things, sglang H3 нужно писать самим (по ~0,5 дня каждый, образец есть).
- Пустой ключ LLM не работает в агенте; названия узлов по-китайски; на 390 px чат закрывает холст.
- Агент на холсте на локальной 27B медленный (30-60 с на шаг) и хрупкий: прогон обрывается при закрытии вкладки, статус «Разговор идёт» залипает.
- Нет тестов; молодая кодовая база; MCP работает только при открытой вкладке.
- Общая вкладка Playwright MCP делилась с агентом ArcReel, поэтому часть работы вёл через свой Chrome-профиль (скрипты `~/Research/studio-eval/toonflow/tools/`).

## Вердикт: **доноры кода**
Идея провайдера как плагина и MCP/A2A-слой стоит перенять, но холстовая модель без «дублей» и сборки не ложится на наш CJM, а основу пришлось бы переписывать.

## Оценка работ, если брать основой
- Провайдеры: ComfyUI (готов, 60 строк, нужны выбор workflow и негатив), sglang H3 по HTTP (0,5 дня), Draw Things через мост (0,5-1 день).
- Сущности «сцена - дубль - сборка», продолжение от хвоста автоматически, склейка: 5-8 дней поверх холста, потому что модель данных - узлы, а не проект/сцены.
- Локализация узлов и мобильный вид: 2-3 дня. Тесты и устойчивость агента на локальной LLM: 3-5 дней.
- Итого основой: ~2-3 недели против тонкого слоя с нуля; как доноры - 1-2 дня на перенос схемы провайдера.
