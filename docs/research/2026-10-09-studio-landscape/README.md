## Что проверить руками (день-два, на Маке, без alex-neuro)

ArcReel и Toonflow в Docker. Исполнители: ComfyUI на Маке (MPS) и Draw Things с Krea 2 / Z-Image.
Чек-лист:
1. Ставится ли и работает ли со своим ComfyUI по адресу.
2. Проект → сцены → дубли → сборка: насколько удобно.
3. Продолжение от последнего кадра.
4. Свой LLM-провайдер. ArcReel идёт на Claude Agent SDK — пустит ли CAILA или OpenAI-совместимый?
5. Русский интерфейс, телефон.
6. MCP и REST: можно ли подключить ai-writer как сценариста и Hermes как проводника.
7. Как добавить свой движок (Draw Things, sglang H3).
8. Живость кода и лицензия: AGPL допустима для себя, но не для раздачи закрытого форка.

H3 проверяется на alex-neuro после ~19.10.

**Исход:**
- кандидат проходит → он основа: ai-writer подключаем как режиссёра через MCP, своё дописываем
  модулями;
- не проходит → тонкий слой над ComfyUI REST + `comfyui-mcp` + модуль клипа ai-writer.

## Итог проверки руками (10.10, `eval-arcreel.md`, `eval-toonflow.md`)

Оба кандидата — **доноры кода, не основа**.
- **Toonflow** (MIT). Построен вокруг холста с узлами, а не вокруг «сцена → дубли → сборка». Готового
  ролика на выходе нет, продолжение от кадра ручное, тестов нет. Берём идею провайдера движка
  одним файлом.
- **ArcReel** (AGPL).
  - Ставится и подключает ComfyUI отлично. Есть декларативные эндпоинты движков, удалённый MCP на
    ~45 инструментов, встроенный `minimax-h3`.
  - Против: агент на Claude Agent SDK не работает с локальной Qwen (шаблон системного сообщения,
    таймаут 600 с), русского нет, продолжения от кадра нет, ядро быстро меняется.
  - Берём идеи. Код без перехода на AGPL не копируем.

**Решение:** свой тонкий слой студии. Исполнители: ComfyUI, Draw Things, sglang. Режиссёр —
ai-writer. MCP — по образцу ArcReel и `comfyui-mcp`.
