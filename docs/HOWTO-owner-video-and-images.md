## 1. Студия — http://192.168.100.50:8766/studio

(Имя `alex-neuro` с Мака не резолвится; можно добавить в `/etc/hosts` строку `192.168.100.50 alex-neuro`.)

1. **Проекты** → «+ Новый проект»: название, формат 16:9 или 9:16, идея.
2. **Герой** → загрузить фото героя или места (до 50 Мп); описание пишет сценарист (кнопка) или вручную (английское описание + короткая портретная фраза).
3. **Сценарий** → «Предложить сцены» (сколько сцен — от 1) → «Применить». Поля каждой сцены: действие, эмоция и игра, звук действий, музыка, состояние на входе/выходе, длительность, сид. Под полями — подсказки (нет эмоции, звук не через материал, кириллица и т. п.). Правки сохраняются сами; если сцену правили в другой вкладке — выбор «Сервер / Моё».
4. **Первый кадр** → «Сделать кадр» → «Подтвердить» → кадр Krea 2 (≈25 с, первый после простоя ≈45 с — ComfyUI поднимается) → «Взять в сцену 1».

Промпт сцены для H3 студия собирает сама — его можно скопировать из карточки сцены («Промпт для H3») и вставить в ComfyUI (раздел 3).

Если что-то не так: перезагрузить страницу; статус сервера — `curl -s http://192.168.100.50:8766/api/studio/health` (ждём `{"ok":true,"schema_version":3}`).

## 2. ComfyUI на alex-neuro: как открыть

ComfyUI студии — копия `~/Projects/comfy-h3` (порт 8189). Видеокартой управляет диспетчер: **сначала взять карту, в конце отдать**, иначе воркер студии или LLM будут ждать / мешать.

```bash
# 1) взять карту (повторять, пока state не станет "ready"; "starting" — ждать ~20–40 с)
ssh alex-neuro 'curl -s -X POST 127.0.0.1:8790/acquire -H "Content-Type: application/json" \
  -d "{\"client\":\"owner\",\"engine\":\"comfy-studio\"}"'

# 2) туннель с Мака (оставить окно открытым)
ssh -N -L 8189:127.0.0.1:8189 alex-neuro
#    и открыть в браузере http://127.0.0.1:8189

# 3) в конце — отдать карту
ssh alex-neuro 'curl -s -X POST 127.0.0.1:8790/release -H "Content-Type: application/json" \
  -d "{\"client\":\"owner\"}"'

# состояние карты и движков
ssh alex-neuro 'curl -s 127.0.0.1:8790/status'
```

- `state: wait_qwen` — на карте поднят Qwen-LLM. Для Krea/Z-Image можно оставить (влезают рядом), для Qwen-Image и H3 — выгрузить: `curl -s -X POST 127.0.0.1:8790/qwen/unload -H "Content-Type: application/json" -d '{"client":"owner"}'` (вернуть потом — `/qwen/restore`, ≈2 мин).
- `state: wait` с причиной — карту держит студия (идёт кадр). Подождать.
- Результаты: на сервере `/home/alex/Outputs/comfy-h3/`, с Мака — `/Volumes/home/Outputs/comfy-h3/` (папка `output` ComfyUI).
- Готовые рабочие графы: в ComfyUI меню **Workflow → Browse Templates** (пакет comfyui-workflow-templates): для H3 — `video_minimax_h3_i2v` (от кадра), `video_minimax_h3_r2v` (по референсам), `…_i2v_continuation`, `…_t2v`; есть шаблоны Z-Image и Qwen-Image. В загрузчиках моделей выбрать файлы из таблиц ниже (имена у нас могут отличаться от шаблона — выбирать из выпадающего списка).
- Наши проверенные графы в API-формате: `docs/h3-modes/comfy-templates/*.graph.json` (перетащить файл в окно ComfyUI; заглушки `__PROMPT__`, `__FIRST_FRAME__` и т. п. заменить в узлах руками). Пределы и параметры — в `*.card.json` рядом.

## 3. Картинки

| Модель | Файлы (выбирать в загрузчиках) | Шаги / cfg / сэмплер | Размер | Время ≈1 Мп | Кириллица в надписях |
|---|---|---|---|---|---|
| **Krea 2** | диффузия `krea2_turbo_int8_convrot`, текст `qwen3vl_4b_int8_convrot`, VAE `qwen_image_vae` | 8 / 1 / euler simple | стороны кратны 64, до 2048 | 5–6 с | **да** |
| **Z-Image Turbo** | `z_image_turbo_int8_convrot`, `qwen_3_4b_fp8_mixed`, `ae` | 8 / 1 / res_multistep simple, shift 3 | кратны 64 | 3 с | нет |
| **Qwen-Image 2512** «Полное» | `qwen_image_2512_fp8_e4m3fn`, `qwen_2.5_vl_7b_fp8_scaled`, `qwen_image_vae` | 50 / 4 / euler simple, shift 3.1, негатив есть | кратны **16**, до ~2 Мп | 58 с | **да** |
| **Qwen-Image «Быстро»** | то же + LoRA `Qwen-Image-2512-Lightning-4steps-V1.0-bf16` сила 1.0 | 4 / 1 | то же | 2,7 с | да |

Размеры, которые точно работают: 1:1 `1024×1024`, 16:9 `1344×768`, 9:16 `768×1344`, 4:3 `1152×896`, 3:4 `896×1152`; Qwen «родные» — `1328×1328`, `1664×928`, `928×1664`.

- **Сид:** один и тот же сид + те же параметры = та же картинка до пикселя (проверено). Удачную — записать сид.
- **Промпт:** по-английски надёжнее для всех трёх; по-русски понимают все. Надпись на картинке — в кавычках; русскую надпись — только Krea 2 или Qwen.
- **Кадр для видео:** 16:9 → `1344×768` (или 896×512 для эскизов), 9:16 → `768×1344`. Картинка-кадр должна совпадать по пропорциям с видео.

### 3.1. Картинка одной командой (без браузера)

Скрипт `make_image.py` (в репо `scripts/make_image.py`, на сервере `/home/alex/Outputs/studio/tools/make_image.py`)
сам берёт карту у диспетчера, собирает граф из нашей карточки модели, ждёт результат и печатает путь. Проверен 23.10:
Krea 2 — 23 с, Z-Image — 15 с, Qwen «Быстро» — 34 с (с холодной загрузкой), Krea 2 + LoRA — 24 с.

```bash
ssh alex-neuro
cd /home/alex/Outputs/studio/tools
python3 make_image.py krea2  "a young woman in a linen dress on a forest path, morning" --seed 11
python3 make_image.py zimage "a wooden cabin by a lake at dawn, mist" --size 1024x1024
python3 make_image.py qwen   'a street sign that reads "ЛЕСНАЯ ТРОПА", forest' --profile fast --size 1328x1328
python3 make_image.py qwen   "..." --profile full --negative "blurry, text artifacts"
python3 make_image.py krea2  "a young woman portrait, soft light" --lora KNP/KNP_000003000.safetensors:0.8
python3 make_image.py krea2  "..." --release        # последняя картинка — отдать карту студии
```

- `--seed` не задан — берётся случайный и печатается (запишите удачный). `--size ШxВ` — кратно 64 (Qwen — 16), по умолчанию 1344x768.
- Результат: `/home/alex/Outputs/comfy-h3/studio/owner-<время>/f_00001_.png`, с Мака `/Volumes/home/Outputs/comfy-h3/studio/…`.
- Если печатает «карта: wait ComfyUI студии занят клиентом studio-worker» — студия недавно рисовала кадр; она сама отдаёт
  карту через 15 мин простоя. Быстрее — когда в студии нет идущей задачи:
  `curl -s -X POST 127.0.0.1:8790/release -H 'Content-Type: application/json' -d '{"client":"studio-worker"}'`.
- Без `--release` карта остаётся за вами (следующие картинки идут без загрузки модели); в конце отдайте её.

## 4. Видео H3

Два режима (два графа):

| | `h3-fl2va` — от кадра | `h3-ref2va` — по референсам |
|---|---|---|
| Что подаётся | первый кадр (картинка) | 1–6 картинок героя/места (`<Picture 1>` … в промпте) |
| Когда | сцена 1 от кадра Krea; **сцены 2+ — от последнего кадра предыдущей** | сцена 1, когда важно лицо героя |

Файлы: диффузия `minimax_h3_fl2va_pruned_int8_convrot` / `minimax_h3_ref2va_pruned_int8_convrot`, текст `qwen3vl_32b_minimax_h3_int8_convrot`, VAE `minimax_h3_video_vae_fp16` + `minimax_h3_audio_vae_fp32`.

**Длина** — только по сетке 17k+5 кадров при 24 к/с: 3 с = **73**, 5 с = 124, 8 с = **192**, 10 с = 243, 14,375 с = **345** (максимум). Стороны кратны 32, до 1344.

**Эскиз → финал:**

| | Шаги | Размер | Время |
|---|---|---|---|
| эскиз (проверить игру и движение) | 20 | 896×512, 3 с | ≈72 с (смена модели fl2va↔ref2va ≈16 с) |
| финал | 50 | 896×512, 8 с (192 к) | ≈12 мин (ref2va 722 с, fl2va 693 с) |

Тот же сид в эскизе и финале даёт ту же сцену в лучшем качестве.

**Цепочка сцен:** у готового ролика сцены 1 взять **последний кадр** (на Маке: `ffmpeg -sseof -0.05 -i scene1.mp4 -frames:v 1 last.png`), загрузить в узел `LoadImage` графа fl2va сцены 2. При склейке у сцены 2 **отбросить первый кадр** (он повторяет последний кадр сцены 1): `ffmpeg -i scene2.mp4 -vf "select='gte(n\,1)'" -af "atrim=start=0.0417" s2cut.mp4`, потом склеить `concat`.

**Референсы:** до 6 картинок (дальше — край памяти). Размер `match` по умолчанию.

### Как писать промпт H3 (проверено на пробах)

- **Игру героя писать явно** в каждой сцене: эмоция и её смена («улыбается, потом удивлённо оборачивается»). Нейтральный промпт = «лицо зомби», руки висят.
- **Звук — физически:** материал и контакт («босые ступни по влажной хвое, мягкий хруст веток»), и чего не слышно («без музыки», «без шагов в обуви»). «Bare footsteps» сам по себе даёт обувь.
- **Реализм:** «плёнка/зерно/halation» = мягкое ретро. Живая съёмка = устройство + тряска + блик, мотивированные сюжетом («снято на телефон на ходу»).
- **Кастинг и стиль — до генерации** (в описании героя/кадра), а не правкой промптов после.
- Кириллицы в промпте H3 избегать (подсказка студии это ловит) — пишите по-английски, имена латиницей.

## 6. Частые вопросы

**Какая LLM сейчас у студии?** Внешняя: **Claude Sonnet 5.5 через CAILA** (провайдер `caila-sonnet`). Это «Сценарист»
(сцены из идеи) и описание героя. Список провайдеров — `/home/alex/Outputs/studio/providers.json` на сервере, ключ —
в `.env` панели (не трогать). Второй провайдер в списке — `qwen-alex-neuro` (локальный Qwen 3.8 27B, `http://127.0.0.1:8000`).

**Можно поменять на Qwen?** Да, но с оговорками:
1. Поднять Qwen: `ssh alex-neuro '~/Projects/qwen/qwen.sh start-shared32'` (контекст 32k, ≈40 ГБ видеопамяти, готов через
   1,5–2,5 мин; статус — `qwen.sh status`).
2. В `providers.json` поменять `"active": "caila-sonnet"` на `"active": "qwen-alex-neuro"` (сделайте копию файла). Студия читает
   файл на каждом вызове — перезапуск не нужен. Вернуть — обратно `caila-sonnet`.
3. Оговорки: «Сценарист» на Qwen **не проверялся** (формат JSON-ответа может не пройти проверку — тогда «Сценарист не
   ответил», переключитесь обратно). Пока поднят Qwen, кадр Krea на шаге 4 и видео **ждут** («Qwen держит карту») —
   соседство LLM с Krea/Z-Image появится в срезе «Картинка» (S2b, задача 12). Для кадра — `qwen.sh stop` или
   `/qwen/unload` через диспетчер.
4. Удобная форма выбора провайдера и чат в самой студии — срез S2c (набор llm-kit уже готов, v0.1.0).

**Могу ли я делать картинки скриптами на машине?** Да — `make_image.py` (раздел 3.1); или вручную: карточка и граф
`/home/alex/Projects/h3-studio/docs/h3-modes/comfy-templates/` → `python3 comfy_template.py <модель>.card.json values.json` →
`curl -X POST 127.0.0.1:8189/prompt -d @payload.json` (сначала взять карту). Для видео H3 скриптом — тот же
`comfy_template.py` с `h3-fl2va.card.json` / `h3-ref2va.card.json` (входы: prompt, seed, steps, width, height, length
по сетке 17k+5, first_frame или ref_images — имена после `POST /upload/image`).

**Подключены ли LoRA к Krea 2 и Z-Image?** Krea 2 — да (с 23.10, раздел 3.2). Z-Image — папка видна, но формат не
проверен; в студии и скрипте LoRA для Z-Image пока нет.

## 7. Если что-то пошло не так

| Симптом | Что сделать |
|---|---|
| ComfyUI не открывается | `ssh alex-neuro 'curl -s 127.0.0.1:8790/status'` — есть ли `comfy-studio` в `own`; если нет — повторить `/acquire` |
| Out of memory | уменьшить размер/длину, убрать референсы до 4; проверить, что Qwen-LLM выгружен (для H3 и Qwen-Image обязательно) |
| Студия «ждёт GPU: Qwen держит карту» | `/qwen/unload` (см. раздел 2) или подождать |
| Студия «ждёт GPU: карту держит owner» | вы забыли `/release` из раздела 2 |
| Карта горячая (> 80 °C) | диспетчер сам ждёт остывания до 72 °C |
| Нужно откатить студию | `ssh alex-neuro 'cd ~/Projects/h3-studio && docker tag h3-studio:prev h3-studio:latest && docker compose -f compose.studio.yaml up -d --no-build'` |
| Вернуть старый диспетчер (без студии) | `ssh alex-neuro 'cd ~/Projects/h3-studio && python3 scripts/studio_dispatcher_rollback.py'` |

Ключи (CAILA и др.) лежат на сервере в `/home/alex/Outputs/h3-panel/.env` — не копировать и не показывать в логах.
