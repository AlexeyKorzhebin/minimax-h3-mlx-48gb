# Сюжет клипа — спека

**Дата:** 2026-08-19. **Статус:** утверждён устно (решения пользователя в диалоге). **Ветка:** main.
**Решения пользователя:** произвольная mp3 на вход (лирика извлекается сама); Qwen пишет
визуальный сценарий; **обязательный гейт: человек читает/правит сценарий сцен и утверждает —
только после этого стартует генерация**. Предпосылка выполнена: P0 декода закрыт (1befc598).

## Суть

Двойная надстройка над clip-проектами:

1. **Авто-лирика**: clip-проект с track.source=import принимает mp3 БЕЗ лирики. Align-задача
   в этом случае гонит Whisper без reference (обычная транскрипция) и кладёт в track:
   raw-транскрипт как lyrics_auto + сегменты с таймстампами (raw_segments). Ослышки Whisper
   допустимы — сценарий пишется по смыслу, не для караоке. С лирикой — прежний путь.
2. **Сценарий (новый этап + гейт)**: между «трек утверждён» и стартом сцен. Кнопка
   «Сгенерировать сюжет» в панели → веб-запрос к LLM (существующая механика provider,
   как чат: ensure_up, потолок памяти — воркер и так не берёт задачи при живом llama) →
   Qwen получает лирику (или raw-транскрипт), секции с таймстампами, caption → возвращает
   по секциям визуальные сцены (постановка/камера/образы по смыслу строк, полный H3-формат,
   visual bible дословно в каждой, правило «без поющих крупным планом лиц» — липсинк
   невозможен по построению, аудио-негативы в видео-промпт не протекают). Схема ответа —
   отдельная SCENARIO_SCHEMA (не раздувать PROMPT_SCHEMA). Сцены ложатся в project.json,
   stages.scenario=awaiting_approval.
3. **Гейт**: панель показывает сцены сюжета редактируемыми (текст промпта, длительность в
   пределах секции); PUT-правки разрешены только до утверждения; «Утвердить сюжет» →
   coverage-нарезка (существующая: снап на сетку, гэпы, style-block) применяется к
   УТВЕРЖДЁННЫМ сценам → старт цепочки. «Перегенерировать сюжет» — повторный LLM-вызов
   (сброс в draft), тоже только до утверждения.

## Механика

- project.json: stages.scenario (только kind=clip; для video/song этап отсутствует/skip);
  track.lyrics_auto, track.raw_segments. Схема обратносовместима (draft у старых).
- Секции для сценария: при лирике — существующие sections; при авто-лирике — Qwen сам
  группирует raw_segments в секции (его ответ несёт границы start/end, привязанные к
  таймстампам сегментов; валидация: покрытие 0→duration).
- build_clip_scenes: вход — утверждённые сцены сюжета (промпт+длительность на секцию)
  вместо процедурного синтеза; процедурный путь остаётся fallback-кнопкой «сюжет без LLM»
  (прежнее поведение, тоже через гейт — сцены редактируемы).
- Маршруты: POST /api/projects/<id>/scenario/generate; PUT /api/projects/<id>/scenario
  (правки сцен, 409 после утверждения); approve/scenario. Гейты в прежнем стиле
  (побочный эффект до approve_stage).
- Существующие clip-проекты и API-контракты не ломаются: scenario для них считается
  пройденным (миграция при чтении).

## Вне рамок

- Караоке-титры, липсинк (ограничение записано в KNOWLEDGE).
- Инструментальные треки без вокала (Whisper молчит — сценарий руками в редакторе сюжета,
  это уже работает через PUT).
- Пересборка видео/song-путей.

## Ворота волны

Живой прогон: произвольная mp3 (suno «Колыбельная») БЕЗ лирики → авто-транскрипт →
сценарий Qwen (проверка правил: без поющих лиц, visual bible, секции покрывают трек) →
правка одной сцены руками → утверждение → генерация → финал. Взгляд глазами + сверка
длительности.
