8. **Автоповтор перевода после 409 может затереть ручной английский текст.** [§19.4, строка 1660](/Users/aleksey.korzhebin/Yandex.Disk.localized/Projects/minimax-h3-mlx-48gb/docs/superpowers/specs/2026-10-10-studio-part1-core-design.md:1660): перевод начался → владелец поправил EN → первоначальный запрос корректно получил 409 → мастер автоматически перезапросил с новой версией → новый перевод записался поверх состояния `owner`. 9. **Диапазон ручного сида проверяется только для начала партии.** [§19.4, строки 1661–1662](/Users/aleksey.korzhebin/Yandex.Disk.localized/Projects/minimax-h3-mlx-48gb/docs/superpowers/specs/2026-10-10-studio-part1-core-design.md:1661): разрешён `S=2^53−1`, затем строится `S+k`. Уже третье значение `9007199254740993` округляется в JavaScript до `9007199254740992`. В интерфейсе разные варианты получают одинаковый отображаемый сид, а «Сид в поле» перестаёт воспроизводить исходный. Проверять нужно `S+N−1 ≤ min(card.inputs.seed.max, 2^53−1)`.

Это не обеспечивает дословное сохранение пользовательских надписей, в том числе при инструкциях внутри переводимого текста.
