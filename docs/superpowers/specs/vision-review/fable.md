## 1. Ответы на §8

**1. Граница верна.** Зря изобретается:
- **Карточки узлов, из которых строится UI.** Для трёх узлов это DSL ради DSL; хватит
  Pydantic-модели входов на узел и явного списка правил (6 картинок, 2–15 с, ориентация).
- **Цепочки как граф задач в базе.** Цепочка одна: «сцена N ждёт кадр N−1» — поле `depends_on`
  в существующей очереди.
- **Узлы на разных машинах и слежение за живостью.** Карта одна; адрес — строка в настройках,
  «жив» — GET перед постановкой.
- **Адаптер ComfyUI заново.** `ltx.py` уже делает шаблон → `/prompt` → `/history`; обобщить до
  «шаблон + подстановки + выходы», прогресс по вебсокету.

Готовое: **AI Movie Studio 2** (github.com/Heroesjouney/AIMovieStudiov2, AGPL-3.0, Next.js +
FastAPI, драйвер к ComfyUI :8188, регистрация workflow по JSON с проверкой недостающих весов,
H3 через узлы Kijai, LTX 2.3, Wan, Krea 2, Z-Image) — это §2–3 видения, уже написанные. Минусы:
112 звёзд, «breaking changes», нет LLM-сценариста, телефона, каскада по кадру. **День на оценку
на Маке** с исходом «ядро / только драйвер и workflow / нет». ComfyUI **App Mode** (03.2026) —
форма над одним workflow без состояния проекта: замена «быстрой пробы», не продукта. SwarmUI —
то же.

**2. Мастер первым. Свой чат — не делать.**
- Все провалы прохода 08.10 (Н1, Н2, Н8) случились в чате. Форма с автосохранением этого класса
  ошибок не имеет.
- Чат с виджетами = компоненты мастера **плюс** оркестрация и 10–60 с LLM на шаг там, где форма
  отвечает сразу. «Быстрее контент» — меньше решений; они уже сняты правилами по умолчанию.
- Чат-проводник появляется бесплатно: MCP (DRAFT (е)) + Hermes. Библиотеки для своего чата
  (assistant-ui, CopilotKit/AG-UI, Vercel AI SDK) есть, но нужны только если после MCP владелец
  всё ещё захочет чат в панели.
- Боковой чат шага «Сценарий» (CJM этап 3) остаётся: сцены списком с diff.

**2а. §5а: Hermes + MCP-сервер — да; MCP Apps — нет, пока не смержено.**
- MCP-сервер с 8–10 операциями подключается через `mcp_servers` в `~/.hermes/config.yaml` (HTTP,
  фильтр инструментов) и попадает в десктоп и Telegram автоматически.
- *MCP Apps в Hermes нет, проверено:* `grep -r 'ui://\|resourceUri\|ext-apps'` по
  `~/.hermes/hermes-agent` (v2026.9.24 = 0.21.5) — ноль. Issue #61095 открыт с 14.08, P3.
  PR #75828 (хост в десктопе, 31 файл, +10 496 строк) открыт без ревью, активность замерла 14.08.
  По комментарию в issue Hermes **отбрасывает `_meta` инструмента**, так что `ui://` до модели не
  доходит. Виджеты на MCP Apps — ставка на чужой немержёный PR.
- *Обход сегодня:* инструмент возвращает текст со структурой плюс `MEDIA:/путь.mp4|png` — шлюз
  сам прикладывает медиа в Telegram и десктоп (`gateway/run.py:1412`; проверить allowlist
  продюсеров, строка 1428). Путь должен быть виден с Мака: MCP-сервер на Маке или SMB-путь
  alex-neuro. Для форм — **ссылка на экран мастера** (`…:8765/#/projects/<id>/drafts`): виджет =
  страница панели.
- *Слоты плагинов десктопа* (`web/src/plugins/slots.ts`): только оболочка и страницы (`sidebar`,
  `chat:top`, `pre-main`), слота в сообщении нет. «Живой проект справа» — плагин в `sidebar`,
  карточки сцен в ленте — нет.
- *Hermes заменяет:* чат, уведомления (Telegram), расписания (cron), «быструю пробу». *Не
  заменяет:* формы мастера, кастинг, дубли, 390 px — в Telegram нет форм, в десктопе нет виджетов
  в ленте. Веб = мастер + «Готовое» + настройки, как в §5а.

**2б. «Не привязана к хосту: стандартный MCP + MCP Apps» — требование верное, но в два слоя.**
Кто рисует MCP Apps сегодня (официальная матрица modelcontextprotocol.io/extensions/client-matrix
и доки хостов, 09.10):

| Хост | Виджеты | Телефон |
|---|---|---|
| Claude web / Desktop | да | **да**: iOS/Android рисуют в нативном WebView (inline-карта, карусель, fullscreen); коннектор сначала добавляется на web/desktop и должен быть **HTTPS из интернета** |
| ChatGPT, Cursor, VS Code Copilot, M365 Copilot, Goose, Postman, MCPJam | да | Goose/VS Code/Cursor — только десктоп; ChatGPT-мобайл не подтверждён |
| OpenClaw | да, opt-in `mcp.apps.enabled`; рисует в web Control UI, слушатель-песочница на порту шлюза +1 (18790) | **да, через Telegram Mini App** — кнопка в DM на последний виджет; нужен опубликованный HTTPS-origin (Tailscale serve/funnel). Slack/Discord — ссылка |
| Hermes | нет (PR #75828 стоит) | нет; только `MEDIA:` в Telegram |

Выводы:
- **Слой 1 — обязательный и хост-независимый:** каждый инструмент полностью пригоден без
  виджета: `structuredContent` + текст + кадры как `ImageContent` (показывают Claude, OpenClaw,
  Hermes) + ссылка на экран мастера. Правило спеки: *никаких app-only инструментов* — иначе Hermes и
  CLI-хосты отваливаются (кейс Fastmail #80841).
- **Слой 2 — MCP Apps как прогрессивное улучшение**, 2–3 дня после того, как компоненты мастера
  есть: `ui://studio/scene-card`, `…/drafts-review` — те же React-компоненты, собранные в один HTML
  ≤ 2 МиБ (лимит OpenClaw), по ограничениям Claude (inline-карта ≤ 2 действия, без вложенной
  прокрутки, просмотр дублей — fullscreen). Проверять на двух хостах: Claude Desktop (+ iPhone) и
  OpenClaw (Control UI + Telegram Mini App). Hermes — когда смержат.
- **Главный барьер — не виджеты, а медиа и сеть.** CSP по умолчанию блокирует все внешние origin;
  видео с `http://alex-neuro:8765` в виджете не загрузится ни в одном хосте — нужен HTTPS-origin
  в `_meta.ui.csp.resourceDomains` (Tailscale serve для тайлнета, funnel для Claude-мобайла) либо
  бинарь ресурсом MCP (пример `video-resource-server`, десятки МБ через хост). Телефон через Claude
  = MCP-сервер студии и медиа **доступны из интернета** — а у панели нет пароля (DRAFT (е)).
  Авторизация MCP — гейт до любого мобильного хоста. Парадокс: самый дешёвый просмотр ролика на
  телефоне сегодня — Telegram через Hermes/OpenClaw (`MEDIA:`/Mini App), без MCP Apps.

**3. Критик.** По кадрам 0/2/4/8 с видит технику (зомби-лицо, пальцы, скачок на стыке) — реально
и дёшево. Не видит драматургию, звук, движение — то, чем владелец оценивает клип. Вреден: в
автоповторе (ложный вердикт = 4–6 мин GPU без человека); на эскизе 20 шагов с критериями про
детали (по `DRAFT-VS-FINAL.md` эскиз не предсказывает свет и резкость лица); на звуке ref2va.
Делать: **линтер промпта до генерации** (есть ли «эмоция и игра», материал звука, одинаковое
описание героя по цепочке) — текст, бесплатно; оценка кадров — только совет. Автоповтор не в
волне 2.

**4. Лишнее / недостающее.** Лишнее — п. 1 плюс «роли по провайдерам в коде с первого дня» (это
строка конфига). Недостаёт: дисковый бюджет и чистка дублей; отмена идущей задачи H3 из UI (у LTX
interrupt есть); идемпотентность постановки (двойной POST с телефона); событийный журнал как
единый источник для SSE, MCP и уведомлений (DRAFT (г) — верно).

**5. Причины провала.**
- *Десять дней в ядро, а день с GPU показывает, что H3 в ComfyUI на Ampere без fp8 не идёт.*
  Снять: заранее прочитать официальный workflow, узлы, память; день 1 с GPU — только смоук; план Б
  — sglang.
- *Переписывание 6,8 + 5,5 тыс. строк и новое ядро (35–55 дней) при цели «контент сейчас».*
  Вертикальные ломтики с проходом владельца после каждого; старая панель живёт.
- *Архитектура не лечит самообслуживание.* Провалы 08.10 — UX-детали; гейт «владелец сам прошёл»
  на каждый ломтик.
- *Критик, чат и MCP Apps съедают бюджет до того, как мастер доведён.*
