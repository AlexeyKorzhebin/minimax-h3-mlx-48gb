# Сводка ревью видения студии (Codex ×2, Fable), 2026-10-09

Источники: `codex.md`, `codex-2-hermes.md`, `fable.md` в этой папке.

## В чём ревьюеры согласны

1. **Граница верна:** мы режиссёр (проект, сцены, дубли, цепочки по кадру, сборка), ComfyUI и
   sglang исполняют.
2. **Порядок неверен.** Универсальное ядро и критик не должны идти раньше пути, который владелец
   проходит сам. Работаем вертикальными срезами, каждый проверяется проходом владельца.
3. **Мастер первым. Свой чат не пишем.** Чат-проводник — любой MCP-хост (Hermes, OpenClaw, Claude,
   Goose) поверх тонкого MCP-сервера студии. MCP-сервер — обёртка над теми же операциями API, без
   своей логики.
4. **Источник состояния один — база студии.** Хост хранит только разговор. Изменения проходят с
   `expected_revision`. Постановка возвращает `job_id` и ключ идемпотентности. Перед затратным
   запуском — подтверждение.
5. **MCP Apps:** в Hermes v0.21.5 их нет (проверили оба; issue открыт, PR #75828 стоит). Сегодня
   работает так: текст + медиа (Hermes сам прикладывает ролик в Telegram и десктоп) + ссылка на
   экран мастера. Пробовать MCP Apps — в Claude, Goose или VS Code. Медиа из песочницы — через
   HTTPS-прокси с короткими ссылками и Range.
6. **Критик — только советник, позже.** Сначала ручные вердикты владельца на 20–30 роликах, потом
   замер ложных срабатываний. Автопересъёмку отложить. Fable предлагает вместо критика начать с
   **линтера промпта до генерации**: проверка эмоции, походки, лимитов, тегов.
7. **Лишнее в ядре сейчас:** карточки узлов, из которых строится UI; граф цепочек в базе (хватит
   `depends_on`); мульти-машинная маршрутизация. Хватит FastAPI + SQLite + worker + существующий
   диспетчер. Адрес узла — строка в настройках.
8. **Не хватало в ядре:**
   - общая блокировка GPU для ComfyUI и H3;
   - восстановление после оборванного ответа (искать задачу перед повтором);
   - неизменяемые входы дубля, чтобы поздний результат не затирал выбранный;
   - лимит референсов, зависящий от длительности;
   - различение «процесс жив» и «модель загружена»;
   - согласованный бэкап SQLite с WAL.
