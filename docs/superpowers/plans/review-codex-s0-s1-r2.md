**Н6 — Важно. Проверка панели не гарантирует отказ при неисправности диагностики.**

**Н7 — Важно. Новый откат может сохранить не тот образ.**  
Место: П:3061–3063, 3081–3084.

`prev` создаётся из `latest`, а не из образа работающего контейнера. После сборки B и отказа тестов контейнер может продолжать работать на A, но `latest` уже указывает на B. Повторная выкладка затрёт `prev` образом B; откат перестанет возвращать A.

**Предложение:** сохранять ID образа работающего контейнера до сборки и использовать уникальный тег выкладки. Проверить последовательность «сборка → отказ проверки → повторная попытка → откат».
