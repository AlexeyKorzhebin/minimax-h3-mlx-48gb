# Студия, срезы S0 и S1 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** владелец открывает `http://alex-neuro:8766/studio`, создаёт проект и видит его после перезагрузки (S0), затем добавляет героя, получает от «Сценариста» сцены из идеи, правит их, видит находки линтера и после перезагрузки находит правки на месте (S1).

**Architecture:** новый пакет `h3_48gb/studio/` рядом со старой панелью (strangler, спека §3): `db.py` (SQLite WAL, миграции по `PRAGMA user_version`), `events.py` (журнал событий в той же транзакции, И8), `ops.py` (явные операции §7 — единственная логика, её зовут и мастер, и будущий MCP), `app.py` (FastAPI, SSE O21, статика мастера), `lint.py`, `llm.py` + `director/` (сценарист и карточка героя через `provider.chat_with_schema`). Мастер — `h3_48gb/studio/web/` (React + Vite + TypeScript, Tailwind v4, компоненты в стиле shadcn на токенах «AB»), собирается в `web/dist` и отдаётся `studio-api`. Старая панель (`web.py`, `compose.yaml`, контейнер `h3-panel` на :8765) не трогается и не импортируется.

**Tech Stack:** Python 3.12, FastAPI 0.156.8 + Pydantic 2.14.1 + uvicorn 0.54.0, `sqlite3` stdlib (SQLite 3.53 на Маке), pytest 8; React 19.3.1, Vite 8.3.5, TypeScript 5.9.3, Tailwind CSS 4.3.3 (`@tailwindcss/vite`), class-variance-authority, lucide-react, `@fontsource/{inter,inter-tight,jetbrains-mono}` 5.3.0, Vitest 5.0.5 + Testing Library + jsdom; Docker compose на alex-neuro.

**Spec:** `docs/superpowers/specs/2026-10-10-studio-part1-core-design.md` (редакция 2 + решения 6–9 §17.1, одобрена владельцем 21.10). Срезы — §14. Вид мастера — `docs/design/2026-10-studio-style/AB/README.md` и `AB/index.html`. Читать спеку §0, §3, §4.4, §5, §6, §7, §9.1, §10, §13, §14 до первой задачи.

**Две части, две приёмки.** Часть A (задачи 1–5) — срез S0, часть B (задачи 6–13) — срез S1. Каждая часть кончается техническим гейтом из §14 и проходом владельца; часть B начинается только после приёмки S0 владельцем. Порядок среза по §14: план → **проверка плана не автором** (`/codex` план против спеки, CLAUDE.md) → реализация → ревью с мутациями → проход владельца.

## Review Focus

1. **Фото героя с iPhone (HEIC).** Владелец снимает телефоном; ожидание — внятный отказ с перечнем форматов, а не 500 и не «битая» картинка. Тест `test_an_iphone_heic_photo_is_refused_with_the_formats_named` (задача 9).
2. **Удаление первой сцены цепочки.** Вторая сцена (`prev_last_frame`) становится первой; ожидание — источник кадра пуст, линт L12 `error`, сохранение проходит, без 500. Тест `test_deleting_the_first_scene_of_a_chain_leaves_an_l12_error_not_a_crash` (задача 10).
3. **Предложение сценариста применяют после того, как проект изменился** (добавили второго героя между «Предложить» и «Применить»). Ожидание — 409 `revision_conflict`, предложение не «сгорает», повтор с новой ревизией применяет его. Тест `test_a_proposal_survives_a_revision_conflict_and_applies_with_the_fresh_revision` (задача 11).
4. **Две вкладки.** Правка разных сцен из двух вкладок — обе сохраняются (O8 не трогает ревизию проекта); правка одной сцены — вторая получает 409 со свежей сценой и мастер говорит об этом словами. Тесты `test_two_tabs_editing_two_scenes_both_save`, `test_patch_with_a_stale_scene_revision_is_409_with_the_current_scene` (задача 10), `tells the owner when the scene changed elsewhere and reloads` (задача 12).
5. **Сценарист недоступен (CAILA лежит, ключа нет).** Ожидание — путь не зависит от LLM (спека §16): герой сохраняется с английским описанием, введённым вручную, сцены добавляются «+ Сцена». Тесты `test_llm_failure_is_502_and_nothing_is_written` (задача 9), `when the LLM is down, asks for the English card and sends it` и `adds a scene that continues from the previous one, keeping existing ids` (задача 12).

```python
from __future__ import annotations

from pathlib import Path


class ConfigError(ValueError):
    pass


def resolve_outdir(raw: str | None, *, home: Path | None = None) -> Path:
    if not raw:
        raise ConfigError("нужен --outdir или переменная H3_OUTDIR")
    path = Path(raw).expanduser().resolve()
    models = ((home or Path.home()) / "models").resolve()
    if path == models or models in path.parents:
        raise ConfigError(f"H3_OUTDIR не может лежать внутри {models}: {path}")
    return path

    """`<outdir>/studio/` — the database, its backups, uploaded assets, providers.json/.env."""
    return outdir / "studio"
```

Create `h3_48gb/studio/db.py`:

```python
"""SQLite for the studio (spec §5, §6): one file, WAL, `busy_timeout=5000`, foreign keys on,
migrations `migrations/NNN_name.sql` applied by `PRAGMA user_version`, each in one transaction."""
from __future__ import annotations

import re
import sqlite3
from contextlib import contextmanager
from datetime import datetime
from pathlib import Path

MIGRATIONS = Path(__file__).parent / "migrations"
_MIGRATION_NAME = re.compile(r"^(\d{3})_[a-z0-9_]+\.sql$")


def connect(path: Path) -> sqlite3.Connection:
    # isolation_level=None: no implicit BEGIN; every write goes through `tx()` below.
    # check_same_thread=False: FastAPI may run a sync dependency and the endpoint that uses it on
    # different threadpool threads; one connection still serves one request at a time.
    conn = sqlite3.connect(path, isolation_level=None, check_same_thread=False, timeout=5.0)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA journal_mode=WAL")
    conn.execute("PRAGMA busy_timeout=5000")
    conn.execute("PRAGMA foreign_keys=ON")
    return conn


def migrations(directory: Path = MIGRATIONS) -> list[tuple[int, Path]]:
    found = []
    for path in sorted(directory.iterdir()):
        match = _MIGRATION_NAME.match(path.name)
        if match:
            found.append((int(match.group(1)), path))
    numbers = [number for number, _ in found]
    if numbers != list(range(1, len(numbers) + 1)):
        raise RuntimeError(f"migrations must be numbered 001.. without gaps, got {numbers}")
    return found


def migrate(conn: sqlite3.Connection, directory: Path = MIGRATIONS) -> int:
    """Apply every migration above `user_version`; return the version reached. A migration that
    fails leaves neither its tables nor its version number behind."""
    current = conn.execute("PRAGMA user_version").fetchone()[0]
    for number, path in migrations(directory):
        if number <= current:
            continue
        sql = path.read_text(encoding="utf-8")
        try:
            conn.executescript(f"BEGIN IMMEDIATE;\n{sql}\nPRAGMA user_version={number};\nCOMMIT;")
        except BaseException:
            if conn.in_transaction:
                conn.execute("ROLLBACK")
            raise
        current = number
    return current


@contextmanager
def tx(conn: sqlite3.Connection):
    """One write transaction. `BEGIN IMMEDIATE` takes the write lock up front, so two writers
    queue on `busy_timeout` instead of failing at their first UPDATE."""
    if conn.in_transaction:
        raise RuntimeError("nested studio transaction")
    conn.execute("BEGIN IMMEDIATE")
    try:
        yield conn
    except BaseException:
        conn.execute("ROLLBACK")
        raise
    conn.execute("COMMIT")


@contextmanager
def read(conn: sqlite3.Connection):
    """One read snapshot: every SELECT inside sees the same committed state (И10 needs the
    snapshot and its `last_seq` to agree)."""
    if conn.in_transaction:
        raise RuntimeError("nested studio transaction")
    conn.execute("BEGIN")
    try:
        yield conn
    finally:
        conn.execute("ROLLBACK")


def backup_once(db_path: Path, dest_dir: Path, *, now: datetime, keep: int = 7) -> Path:
    """Consistent copy through `Connection.backup()` (a plain file copy of a WAL database is not
    consistent, spec §5); keeps the newest `keep` copies by name."""
    dest_dir.mkdir(parents=True, exist_ok=True)
    target = dest_dir / f"studio-{now:%Y%m%d-%H%M%S}.sqlite"
    src = sqlite3.connect(db_path)
    dst = sqlite3.connect(target)
    try:
        src.backup(dst)
    finally:
        dst.close()
        src.close()
    copies = sorted(dest_dir.glob("studio-*.sqlite"))
    for old in copies[:-keep]:
        old.unlink()
    return target
```

```python
"""The event journal (spec §5 «События», И8): a row per change, written inside the change's own
transaction, read by the SSE stream (O21) after a sequence number."""
from __future__ import annotations

import json
import sqlite3

from h3_48gb.studio import ids


def emit(conn: sqlite3.Connection, kind: str, *, project_id: str | None = None,
         scene_id: str | None = None, task_id: str | None = None,
         payload: dict | None = None) -> int:
    if not conn.in_transaction:
        raise RuntimeError(f"event {kind!r} emitted outside a transaction (И8)")
    cur = conn.execute(
        "INSERT INTO event (ts, kind, project_id, scene_id, task_id, payload_json) "
        "VALUES (?, ?, ?, ?, ?, ?)",
        (ids.now_iso(), kind, project_id, scene_id, task_id,
         json.dumps(payload or {}, ensure_ascii=False, sort_keys=True)))
    return cur.lastrowid


def last_seq(conn: sqlite3.Connection) -> int:
    return conn.execute("SELECT COALESCE(MAX(seq), 0) FROM event").fetchone()[0]


def read_after(conn: sqlite3.Connection, after: int, limit: int = 100) -> list[dict]:
    rows = conn.execute(
        "SELECT seq, ts, kind, project_id, scene_id, task_id, payload_json FROM event "
        "WHERE seq > ? ORDER BY seq LIMIT ?", (after, limit)).fetchall()
    return [{"seq": r["seq"], "ts": r["ts"], "kind": r["kind"], "project_id": r["project_id"],
             "scene_id": r["scene_id"], "task_id": r["task_id"],
             "payload": json.loads(r["payload_json"])} for r in rows]


def sse_frame(event: dict) -> str:
    data = json.dumps(event, ensure_ascii=False, sort_keys=True)
    return f"id: {event['seq']}\nevent: {event['kind']}\ndata: {data}\n\n"
```

```python
"""Explicit studio operations (spec §7). The master and MCP both call these and nothing else.
Every write is one `db.tx` that also writes its event (И8)."""
from __future__ import annotations

import sqlite3

from h3_48gb.studio import db, events, ids
from h3_48gb.studio.errors import StudioError

FRAME_FORMATS = ("16:9", "9:16")


def _project_row(conn: sqlite3.Connection, project_id: str) -> sqlite3.Row:
    row = conn.execute("SELECT * FROM project WHERE id = ?", (project_id,)).fetchone()
    if row is None:
        raise StudioError(404, "project_not_found", "Проект не найден",
                          {"project_id": project_id})
    return row


def require_project(conn: sqlite3.Connection, project_id: str) -> None:
    _project_row(conn, project_id)


def project_out(row: sqlite3.Row) -> dict:
    return {"id": row["id"], "revision": row["revision"], "title": row["title"],
            "frame_format": row["frame_format"], "idea_text": row["idea_text"],
            "style_block": row["style_block"], "created_at": row["created_at"]}


def create_project(conn: sqlite3.Connection, *, title: str, frame_format: str,
                   idea_text: str = "") -> dict:
    project_id = ids.new_id("p")
    with db.tx(conn):
        conn.execute(
            "INSERT INTO project (id, revision, title, frame_format, idea_text, created_at) "
            "VALUES (?, 1, ?, ?, ?, ?)",
            (project_id, title, frame_format, idea_text, ids.now_iso()))
        events.emit(conn, "project_created", project_id=project_id,
                    payload={"title": title, "frame_format": frame_format})
        return project_out(_project_row(conn, project_id))


def list_projects(conn: sqlite3.Connection) -> list[dict]:
    rows = conn.execute(
        "SELECT p.*, "
        " (SELECT COUNT(*) FROM scene s WHERE s.project_id = p.id AND s.deleted_at IS NULL)"
        "   AS scenes_total, "
        " (SELECT COUNT(*) FROM scene s WHERE s.project_id = p.id AND s.deleted_at IS NULL"
        "   AND s.approved_final_take_id IS NOT NULL) AS scenes_done "
        "FROM project p ORDER BY p.created_at DESC, p.id").fetchall()
    return [{**project_out(r), "scenes_total": r["scenes_total"], "scenes_done": r["scenes_done"]}
            for r in rows]


def _check_revision(row: sqlite3.Row, expected: int, current: dict) -> None:
    if row["revision"] != expected:
        raise StudioError(409, "revision_conflict",
                          "Данные изменились в другом окне — обновите и повторите",
                          {"current": current})


def update_project(conn: sqlite3.Connection, project_id: str, *, expected_revision: int,
                   title: str | None = None, frame_format: str | None = None) -> dict:
    with db.tx(conn):
        row = _project_row(conn, project_id)
        _check_revision(row, expected_revision, project_out(row))
        changes: dict = {}
        if title is not None and title != row["title"]:
            changes["title"] = title
        if frame_format is not None and frame_format != row["frame_format"]:
            done = conn.execute(
                "SELECT COUNT(*) FROM take t JOIN scene s ON s.id = t.scene_id "
                "WHERE s.project_id = ? AND t.status = 'done'", (project_id,)).fetchone()[0]
            if done:
                raise StudioError(409, "format_locked",
                                  "Формат кадра нельзя менять после первого готового дубля",
                                  {"done_takes": done})
            changes["frame_format"] = frame_format
        if not changes:
            return project_out(row)
        sets = ", ".join(f"{name} = ?" for name in changes)
        conn.execute(f"UPDATE project SET {sets}, revision = revision + 1 WHERE id = ?",
                     (*changes.values(), project_id))
        events.emit(conn, "project_updated", project_id=project_id, payload=changes)
        return project_out(_project_row(conn, project_id))


def snapshot(conn: sqlite3.Connection, project_id: str) -> dict:
    """O3: the project with everything the master draws, and the `last_seq` it is consistent
    with (И10) — read in one snapshot so an event committed in between cannot be lost. Scenes
    and cast arrive in slice S1; takes and tasks in S2–S3."""
    with db.read(conn):
        project = project_out(_project_row(conn, project_id))
        return {"project": project, "scenes": [], "cast": [], "takes": [], "tasks": [],
                "last_seq": events.last_seq(conn)}
```

```python
"""Helpers for the studio tests, imported by name (not a conftest: a fixture out of thin air is
harder to follow). `LiveServer` runs the real app under uvicorn on a kernel-chosen port — the SSE
stream is tested over a socket, the way the browser reads it, not through an in-process client."""
from __future__ import annotations

import http.client
import json
import socket
import threading
import time
from pathlib import Path

import uvicorn
from fastapi.testclient import TestClient

from h3_48gb.studio.app import create_app


def make_client(tmp_path: Path, **kwargs) -> TestClient:
    return TestClient(create_app(tmp_path / "out", **kwargs))


class LiveServer:
    def __init__(self, app):
        self.server = uvicorn.Server(uvicorn.Config(app, host="127.0.0.1", port=0,
                                                    log_level="warning",
                                                    timeout_graceful_shutdown=1))
        self.thread = threading.Thread(target=self.server.run, daemon=True)
        self.port = 0

    def __enter__(self):
        self.thread.start()
        deadline = time.monotonic() + 10
        while not self.server.started:
            if time.monotonic() > deadline:
                raise RuntimeError("uvicorn did not start in 10 s")
            time.sleep(0.02)
        self.port = self.server.servers[0].sockets[0].getsockname()[1]
        return self

    def __exit__(self, *exc):
        self.server.should_exit = True
        self.thread.join(10)


def read_sse(port: int, path: str, *, headers: dict | None = None, count: int,
             timeout: float = 3.0) -> list[dict]:
    """Up to `count` events from an SSE stream, or fewer if `timeout` passes first. Each event is
    `{"id": int, "event": str, "data": dict}`; comment lines (`: ping`) are skipped."""
    conn = http.client.HTTPConnection("127.0.0.1", port, timeout=timeout)
    conn.request("GET", path, headers=headers or {})
    resp = conn.getresponse()
    assert resp.status == 200, resp.status
    got: list[dict] = []
    current: dict = {}
    deadline = time.monotonic() + timeout
    try:
        while len(got) < count and time.monotonic() < deadline:
            try:
                line = resp.fp.readline().decode("utf-8")
            except (socket.timeout, TimeoutError):
                break
            if not line:
                break
            line = line.rstrip("\n")
            if line.startswith(":"):
                continue
            if line == "":
                if current:
                    got.append(current)
                    current = {}
                continue
            name, _, value = line.partition(": ")
            if name == "id":
                current["id"] = int(value)
            elif name == "event":
                current["event"] = value
            elif name == "data":
                current["data"] = json.loads(value)
    finally:
        conn.close()
    return got
```

```python
"""The studio API (spec §4.2 `studio-api`, §7): FastAPI over `ops`, the SSE journal (O21) and the
built master under `/studio`."""
from __future__ import annotations

import asyncio
import contextlib
from datetime import datetime
from pathlib import Path

from fastapi import Depends, FastAPI, Header, Request
from fastapi.exceptions import RequestValidationError
from fastapi.responses import FileResponse, JSONResponse, RedirectResponse, StreamingResponse
from starlette.exceptions import HTTPException as StarletteHTTPException

from h3_48gb.studio import config, db, events, ops, schemas
from h3_48gb.studio.errors import StudioError

WEB_DIST = Path(__file__).parent / "web" / "dist"
SSE_POLL_S = 0.25
SSE_HEARTBEAT_S = 15.0
BACKUP_EVERY_S = 3600.0


def create_app(outdir: Path, *, web_dist: Path = WEB_DIST) -> FastAPI:
    home = config.studio_dir(outdir)
    home.mkdir(parents=True, exist_ok=True)
    db_path = home / "studio.sqlite"
    boot = db.connect(db_path)
    try:
        db.migrate(boot)
    finally:
        boot.close()

    @contextlib.asynccontextmanager
    async def lifespan(_app: FastAPI):
        async def backups():
            while True:
                await asyncio.sleep(BACKUP_EVERY_S)
                await asyncio.to_thread(db.backup_once, db_path, home / "backups",
                                        now=datetime.now())
        task = asyncio.create_task(backups())
        try:
            yield
        finally:
            task.cancel()

    app = FastAPI(title="h3 studio", version="0.1.0", lifespan=lifespan)
    app.state.outdir = outdir
    app.state.db_path = db_path

    @app.exception_handler(StudioError)
    async def _studio_error(_request: Request, exc: StudioError):
        return JSONResponse(exc.body(), status_code=exc.status)

    @app.exception_handler(RequestValidationError)
    async def _invalid(_request: Request, exc: RequestValidationError):
        errors = [{"loc": list(e["loc"]), "msg": e["msg"]} for e in exc.errors()]
        return JSONResponse({"error": {"code": "args_invalid", "message": "Неверные данные запроса",
                                       "detail": {"errors": errors}}}, status_code=400)

    @app.exception_handler(StarletteHTTPException)
    async def _http(_request: Request, exc: StarletteHTTPException):
        code = "not_found" if exc.status_code == 404 else "http_error"
        return JSONResponse({"error": {"code": code, "message": str(exc.detail), "detail": {}}},
                            status_code=exc.status_code)

    def get_conn():
        conn = db.connect(db_path)
        try:
            yield conn
        finally:
            conn.close()

    def project_exists(project_id: str, conn=Depends(get_conn)) -> str:
        # A dependency, so a missing project answers 404 before the body is validated (§7).
        ops.require_project(conn, project_id)
        return project_id

    api = "/api/studio"

    @app.get(f"{api}/health")
    def health(conn=Depends(get_conn)):
        return {"ok": True, "schema_version": conn.execute("PRAGMA user_version").fetchone()[0]}

    @app.get(f"{api}/projects")
    def list_projects(conn=Depends(get_conn)):
        return ops.list_projects(conn)

    @app.post(f"{api}/projects", status_code=201)
    def create_project(body: schemas.ProjectCreate, conn=Depends(get_conn)):
        return ops.create_project(conn, title=body.title, frame_format=body.frame_format,
                                  idea_text=body.idea_text)

    @app.get(f"{api}/projects/{{project_id}}")
    def get_project(project_id: str = Depends(project_exists), conn=Depends(get_conn)):
        return ops.snapshot(conn, project_id)

    @app.patch(f"{api}/projects/{{project_id}}")
    def patch_project(body: schemas.ProjectPatch, project_id: str = Depends(project_exists),
                      conn=Depends(get_conn)):
        return ops.update_project(conn, project_id, expected_revision=body.expected_revision,
                                  title=body.title, frame_format=body.frame_format)

    @app.get(f"{api}/events")
    async def stream_events(request: Request, after: int = 0,
                            last_event_id: int | None = Header(default=None)):
        start = max(after, last_event_id or 0)

        async def frames():
            seen = start
            idle = 0.0
            conn = db.connect(db_path)
            try:
                while not await request.is_disconnected():
                    batch = await asyncio.to_thread(events.read_after, conn, seen)
                    for event in batch:
                        seen = event["seq"]
                        yield events.sse_frame(event)
                    if batch:
                        idle = 0.0
                        continue
                    await asyncio.sleep(SSE_POLL_S)
                    idle += SSE_POLL_S
                    if idle >= SSE_HEARTBEAT_S:
                        idle = 0.0
                        yield ": ping\n\n"
            finally:
                conn.close()

        return StreamingResponse(frames(), media_type="text/event-stream",
                                 headers={"Cache-Control": "no-store", "X-Accel-Buffering": "no"})

    @app.get("/")
    def root():
        return RedirectResponse("/studio/")

    @app.get("/studio")
    @app.get("/studio/{path:path}")
    def master(path: str = ""):
        index = web_dist / "index.html"
        if not index.is_file():
            raise StudioError(503, "web_not_built",
                              "Мастер не собран: npm --prefix h3_48gb/studio/web run build")
        candidate = (web_dist / path).resolve()
        if path and candidate.is_file() and web_dist.resolve() in candidate.parents:
            return FileResponse(candidate)
        return FileResponse(index)

    return app
```

```ts
import { vi } from "vitest";

/** Replies keyed by the exact "METHOD URL" string. Anything else fails the test: a stub that
 *  matched loosely (startsWith/includes) has let mutations survive in this repo before. */
export type Reply = { status?: number; body: unknown };
export type Call = { key: string; body: unknown };

export function stubFetch(routes: Record<string, Reply | Reply[]>) {
  const calls: Call[] = [];
  const queues = new Map(Object.entries(routes).map(([k, v]) => [k, Array.isArray(v) ? [...v] : [v]]));
  vi.stubGlobal("fetch", async (url: string, init?: RequestInit) => {
    const key = `${init?.method ?? "GET"} ${url}`;
    const raw = init?.body;
    calls.push({ key, body: typeof raw === "string" ? JSON.parse(raw) : raw ?? null });
    const queue = queues.get(key);
    if (!queue || queue.length === 0) throw new Error(`unexpected fetch: ${key}`);
    const reply = queue.length > 1 ? queue.shift()! : queue[0];
    return new Response(JSON.stringify(reply.body), {
      status: reply.status ?? 200,
      headers: { "Content-Type": "application/json" },
    });
  });
  return calls;
}

/** EventSource that records its URL and lets the test push events by name. */
export class FakeEventSource {
  static last: FakeEventSource | null = null;
  url: string;
  listeners = new Map<string, ((e: MessageEvent) => void)[]>();
  closed = false;
  constructor(url: string) {
    this.url = url;
    FakeEventSource.last = this;
  }
  addEventListener(kind: string, fn: (e: MessageEvent) => void) {
    this.listeners.set(kind, [...(this.listeners.get(kind) ?? []), fn]);
  }
  emit(kind: string, data: unknown, id: number) {
    for (const fn of this.listeners.get(kind) ?? []) {
      fn(new MessageEvent(kind, { data: JSON.stringify(data), lastEventId: String(id) }));
    }
  }
  close() {
    this.closed = true;
  }
}
```

```ts
import type { ApiErrorBody } from "./types";

export const API = "/api/studio";

export class ApiError extends Error {
  status: number;
  code: string;
  detail: Record<string, unknown>;
  constructor(status: number, code: string, message: string, detail: Record<string, unknown>) {
    super(message);
    this.status = status;
    this.code = code;
    this.detail = detail;
  }
}

async function parse<T>(res: Response): Promise<T> {
  const text = await res.text();
  const body = text ? JSON.parse(text) : null;
  if (res.ok) return body as T;
  const err = (body as ApiErrorBody | null)?.error;
  if (err) throw new ApiError(res.status, err.code, err.message, err.detail ?? {});
  throw new ApiError(res.status, "http_error", `Сервер ответил ${res.status}`, {});
}

export async function api<T>(method: string, path: string, body?: unknown): Promise<T> {
  const init: RequestInit = { method };
  if (body !== undefined) {
    init.headers = { "Content-Type": "application/json" };
    init.body = JSON.stringify(body);
  }
  return parse<T>(await fetch(`${API}${path}`, init));
}

export async function upload<T>(path: string, file: File, fields: Record<string, string> = {}) {
  const form = new FormData();
  form.append("file", file);
  for (const [k, v] of Object.entries(fields)) form.append(k, v);
  return parse<T>(await fetch(`${API}${path}`, { method: "POST", body: form }));
}
```

```ts
export type ThemeChoice = "light" | "dark" | "system";
const KEY = "studio.theme";
const ORDER: ThemeChoice[] = ["light", "dark", "system"];

export function readTheme(): ThemeChoice {
  try {
    const v = localStorage.getItem(KEY);
    return v === "light" || v === "dark" || v === "system" ? v : "system";
  } catch {
    return "system";
  }
}

export function applyTheme(choice: ThemeChoice) {
  const dark = choice === "dark" || (choice === "system" && matchMedia("(prefers-color-scheme: dark)").matches);
  document.documentElement.dataset.theme = dark ? "dark" : "light";
  try {
    localStorage.setItem(KEY, choice);
  } catch {
    /* private mode: the choice lives until reload */
  }
}

export function nextTheme(choice: ThemeChoice): ThemeChoice {
  return ORDER[(ORDER.indexOf(choice) + 1) % ORDER.length];
}

export const THEME_LABEL: Record<ThemeChoice, string> = {
  light: "Светлая",
  dark: "Тёмная",
  system: "Как в системе",
```

```ts
export function parseHash(hash: string): Route {

export function useRoute(): Route {
  const [route, setRoute] = useState(() => parseHash(location.hash));
  useEffect(() => {

    addEventListener("hashchange", on);
    return () => removeEventListener("hashchange", on);
```

```ts
/** O21: subscribe after `afterSeq` (И10: the snapshot's last_seq) and call `onEvent` for the
 *  listed kinds. EventSource itself resends Last-Event-ID on reconnect. */
export function useEvents(afterSeq: number | null, kinds: string[], onEvent: (kind: string, seq: number) => void) {
  const handler = useRef(onEvent);
  handler.current = onEvent;
  const kindsKey = kinds.join(",");
  useEffect(() => {
    if (afterSeq === null) return;
    const source = new EventSource(`${API}/events?after=${afterSeq}`);
    for (const kind of kindsKey.split(",")) {
      source.addEventListener(kind, (e) => handler.current(kind, Number((e as MessageEvent).lastEventId)));
    }
    return () => source.close();
  }, [afterSeq, kindsKey]);
}
```

```python
"""Scene length (spec §6.2): `requested_s` is kept as typed; `frames` is the nearest point of the
17n+5 grid at 24 fps (ties go up), clamped to [73, 345] = 3.042–14.375 s."""
from __future__ import annotations

from fractions import Fraction

from h3_48gb.engines.sglang_args import FPS, FRAME_REMAINDER, FRAMES_PER_CHUNK

MIN_FRAMES = 73
MAX_FRAMES = 345
MIN_SECONDS = 3.0
MAX_SECONDS = 15.0


def snap_frames(requested_s: float) -> int:
    # Fraction: 4.8125 s is exactly 115.5 frames, halfway between 107 and 124; float arithmetic
    # must not decide that tie.
    target = Fraction(requested_s) * FPS
    low = FRAME_REMAINDER + FRAMES_PER_CHUNK * int((target - FRAME_REMAINDER) // FRAMES_PER_CHUNK)
    high = low + FRAMES_PER_CHUNK
    frames = low if target - low < high - target else high
    return min(max(frames, MIN_FRAMES), MAX_FRAMES)


def seconds(frames: int) -> float:
    return frames / FPS
```

```python
def _chain(project: LintProject, scene: LintScene) -> list[LintScene]:
    """Scenes linked to `scene` by prev_last_frame, in play order."""
    by_id = {s.id: s for s in project.scenes}
    root = scene
    seen = {root.id}
    while root.source_frame_kind == "prev_last_frame" and root.source_scene_id in by_id \
            and root.source_scene_id not in seen:
        root = by_id[root.source_scene_id]
        seen.add(root.id)
    chain = [root]
    while True:
        nxt = next((s for s in project.scenes if s.source_frame_kind == "prev_last_frame"
                    and s.source_scene_id == chain[-1].id and s not in chain), None)
        if nxt is None:
            return chain
        chain.append(nxt)


def l6_portrait_drift(scene, project, limits):
    chain = _chain(project, scene)
    out = []
    for tag, phrase in sorted(project.portrait_phrases.items()):
        if not phrase:

        first = next((s for s in chain if phrase in s.action_text), None)
        if first is None or first.idx >= scene.idx or phrase in scene.action_text:

    return out
```

```python
"""The studio's door to an LLM (spec §9.1, §8.4). `Llm` is what ops and the director depend on;
`ProviderLlm` is the real one over `provider.chat_with_schema`, configured by
`<outdir>/studio/providers.json` + `.env` (the same roster format as the old panel)."""
from __future__ import annotations

import fcntl
import os
import time
from contextlib import contextmanager
from pathlib import Path
from typing import Protocol

from h3_48gb import provider
from h3_48gb.studio.errors import StudioError


class Llm(Protocol):
    label: str

    def json_turn(self, messages: list[dict], schema: dict, retry_reminder: str) -> dict: ...


@contextmanager
def gpu_lock(path: Path, *, enabled: bool, timeout_s: float):
    """§8.4 `local-mac`: an LLM that shares the GPU waits for the same flock the worker holds
    while rendering — at most `timeout_s`, then 409 `gpu_busy` instead of hanging the request."""
    if not enabled:
        yield
        return
    path.parent.mkdir(parents=True, exist_ok=True)
    fd = os.open(path, os.O_RDWR | os.O_CREAT, 0o644)
    try:
        deadline = time.monotonic() + timeout_s
        while True:
            try:
                fcntl.flock(fd, fcntl.LOCK_EX | fcntl.LOCK_NB)
                break
            except BlockingIOError:
                if time.monotonic() >= deadline:
                    raise StudioError(409, "gpu_busy",
                                      "Сценарист ждёт видеокарту: её занял рендер",
                                      {"lock": str(path)}) from None
                time.sleep(0.1)
        try:
            yield
        finally:
            fcntl.flock(fd, fcntl.LOCK_UN)
    finally:
        os.close(fd)


class ProviderLlm:
    def __init__(self, home: Path, lock_path: Path, *, provider_name: str | None = None,
                 lock_timeout_s: float = 5.0):

        self.lock_path = lock_path
        self.provider_name = provider_name
        self.lock_timeout_s = lock_timeout_s

    def _config(self) -> tuple[str, dict]:
        roster = provider.load_providers(self.home)
        name = self.provider_name or roster["active"]
        cfg = roster["providers"].get(name) if name else None
        if cfg is None:
            raise StudioError(503, "llm_not_configured",
                              "Сценарист не настроен: нет провайдера в studio/providers.json",
                              {"provider": name})
        if not cfg["available"]:
            raise StudioError(503, "llm_not_configured",
                              f"Сценарист не настроен: {cfg['reason']}", {"provider": name})
        return name, cfg

    @property
    def label(self) -> str:
        try:
            name, cfg = self._config()
        except StudioError:
            return "none"
        return f"{name}:{cfg.get('model', cfg.get('preset', ''))}"

    def json_turn(self, messages: list[dict], schema: dict, retry_reminder: str) -> dict:
        name, cfg = self._config()
        with gpu_lock(self.lock_path, enabled=provider.shares_gpu(cfg) is True,
                      timeout_s=self.lock_timeout_s):
            try:
                return provider.chat_with_schema(cfg, provider.load_env(self.home), messages,
                                                 schema, retry_reminder)
            except provider.ProviderError as err:
                raise StudioError(502, "llm_failed", f"Сценарист не ответил: {err}",
                                  {"provider": name, "provider_code": err.code}) from err
```

```python
"""Uploaded files (spec §7 O6, И7): stored once under `<outdir>/studio/assets/<id>.<ext>`, never
overwritten; the row is immutable (trigger in migration 001)."""
from __future__ import annotations

import hashlib
import sqlite3
from pathlib import Path

from h3_48gb.studio import db, events, ids
from h3_48gb.studio.errors import StudioError

MAX_ASSET_BYTES = 25 * 1024 * 1024

#: (family, ext, mime) by leading bytes. Only what slice S1 accepts: pictures and voice.
def sniff(data: bytes) -> tuple[str, str, str] | None:
    if data.startswith(b"\x89PNG\r\n\x1a\n"):
        return "image", "png", "image/png"
    if data.startswith(b"\xff\xd8\xff"):
        return "image", "jpg", "image/jpeg"
    if data[:4] == b"RIFF" and data[8:12] == b"WEBP":
        return "image", "webp", "image/webp"
    if data[:4] == b"RIFF" and data[8:12] == b"WAVE":
        return "audio", "wav", "audio/wav"
    if data.startswith(b"fLaC"):
        return "audio", "flac", "audio/flac"
    if data.startswith(b"ID3") or data[:2] in (b"\xff\xfb", b"\xff\xf3", b"\xff\xf2"):
        return "audio", "mp3", "audio/mpeg"
    return None


def asset_out(row: sqlite3.Row) -> dict:
    return {"id": row["id"], "kind": row["kind"], "sha256": row["sha256"], "bytes": row["bytes"],
            "mime": row["mime"], "url": f"/api/studio/assets/{row['id']}/file"}


def import_asset(conn: sqlite3.Connection, home: Path, *, data: bytes,
                 kind: str | None = None) -> dict:
    if len(data) > MAX_ASSET_BYTES:
        raise StudioError(413, "asset_too_large", "Файл больше 25 МБ",
                          {"bytes": len(data), "max": MAX_ASSET_BYTES})
    sniffed = sniff(data)
    if sniffed is None:
        raise StudioError(400, "asset_type_invalid", "Нужна картинка (PNG, JPEG, WebP) или звук "
                          "(WAV, FLAC, MP3)")
    family, ext, mime = sniffed
    if kind is not None and kind != family:
        raise StudioError(400, "asset_type_invalid", f"Файл — {family}, а ожидался {kind}",
                          {"sniffed": family, "kind": kind})
    asset_id = ids.new_id("a")
    folder = home / "assets"
    folder.mkdir(parents=True, exist_ok=True)
    path = folder / f"{asset_id}.{ext}"
    with open(path, "xb") as fh:          # "x": never overwrite an existing asset file (И7)
        fh.write(data)
    try:
        with db.tx(conn):
            conn.execute(
                "INSERT INTO asset (id, kind, path, sha256, bytes, mime, origin_kind, created_at) "
                "VALUES (?, ?, ?, ?, ?, ?, 'upload', ?)",
                (asset_id, family, str(path), hashlib.sha256(data).hexdigest(), len(data), mime,
                 ids.now_iso()))
            events.emit(conn, "asset_imported", payload={"asset_id": asset_id, "kind": family})
            return asset_out(conn.execute("SELECT * FROM asset WHERE id = ?",
                                          (asset_id,)).fetchone())
    except BaseException:
        path.unlink(missing_ok=True)
        raise


def asset_file(conn: sqlite3.Connection, asset_id: str) -> tuple[Path, str]:
    row = conn.execute("SELECT path, mime FROM asset WHERE id = ?", (asset_id,)).fetchone()
    if row is None or not Path(row["path"]).is_file():
        raise StudioError(404, "asset_not_found", "Файл не найден", {"asset_id": asset_id})
    return Path(row["path"]), row["mime"]
```

```python
    "name": "studio_cast_card",
    "schema": {
        "type": "object",
        "properties": {"description_en": {"type": "string"},

def check_card(description_en: str, portrait_phrase: str) -> None:
    """The same checks for a model's card and for one typed by hand."""
    for name, text in (("description_en", description_en), ("portrait_phrase", portrait_phrase)):
        if not text.strip():
            raise StudioError(400, "cast_card_invalid", f"Пустое поле {name}", {"field": name})
        if _CYRILLIC.search(text):
            raise StudioError(400, "cast_card_invalid", f"Кириллица в {name}: нужен английский",
                              {"field": name})
    if len(portrait_phrase.split()) > MAX_PORTRAIT_WORDS:
        raise StudioError(400, "cast_card_invalid",
                          f"Портретная фраза длиннее {MAX_PORTRAIT_WORDS} слов",
                          {"field": "portrait_phrase"})


def describe(llm: Llm, *, tag: str, description_ru: str) -> dict:
    messages = [{"role": "system", "content": PROMPT.read_text(encoding="utf-8")},
                {"role": "user", "content": json.dumps({"tag": tag,
                                                        "description_ru": description_ru},
                                                       ensure_ascii=False)}]
    card = llm.json_turn(messages, CAST_SCHEMA,
                         "Ответ строго одним JSON-объектом {description_en, portrait_phrase}.")
    description_en = card["description_en"].strip()
    portrait_phrase = card["portrait_phrase"].strip().rstrip(".")
    try:
        check_card(description_en, portrait_phrase)
    except StudioError as err:
        raise StudioError(502, "llm_failed", f"Карточка героя от модели не годится: {err.message}",
                          err.detail) from err
```

```python
        "SELECT c.tag FROM scene_ref r JOIN cast_member c ON c.id = r.cast_id "
        "WHERE r.scene_id = ? ORDER BY r.ord", (scene_id,))]


def scene_out(conn: sqlite3.Connection, row: sqlite3.Row) -> dict:
    return {"id": row["id"], "idx": row["idx"], "revision": row["revision"],
            "state_version": row["state_version"], "mode": row["mode"],
            **{f: row[f] for f in TEXT_FIELDS},
            "requested_s": row["requested_s"], "frames": row["frames"],
            "duration_s": round(duration.seconds(row["frames"]), 3), "seed": row["seed"],
            "source_frame": {"kind": row["source_frame_kind"], "scene_id": row["source_scene_id"],
                             "asset_id": row["source_frame_asset_id"]},
            "refs": _ref_tags(conn, row["id"]), "review_state": row["review_state"],
            "approved_sketch_take_id": row["approved_sketch_take_id"],
            "approved_final_take_id": row["approved_final_take_id"]}


def _live_scenes(conn: sqlite3.Connection, project_id: str) -> list[sqlite3.Row]:
    return conn.execute("SELECT * FROM scene WHERE project_id = ? AND deleted_at IS NULL "
                        "ORDER BY idx", (project_id,)).fetchall()


def _scene_row(conn: sqlite3.Connection, scene_id: str) -> sqlite3.Row:
    row = conn.execute("SELECT * FROM scene WHERE id = ? AND deleted_at IS NULL",
                       (scene_id,)).fetchone()
    if row is None:
        raise StudioError(404, "scene_not_found", "Сцена не найдена", {"scene_id": scene_id})
    return row


def _fingerprint(fields, refs: list[tuple[str, int, str]]) -> tuple:
    return (*(fields[name] for name in FINGERPRINT_FIELDS), tuple(refs))


def _resolve_source(conn: sqlite3.Connection, source: dict, *, prev_id: str | None,
                    allowed_scene_ids: set[str]) -> tuple[str, str | None, str | None]:
    kind = source["kind"]
    if kind == "none":
        return "none", None, None
    if kind == "prev_last_frame":
        scene_id = source.get("scene_id") or prev_id
        if scene_id is not None and scene_id not in allowed_scene_ids:
            raise StudioError(400, "source_scene_unknown", "Источник кадра — не сцена этого проекта",
                              {"scene_id": scene_id})
        return "prev_last_frame", scene_id, None
    asset_id = source.get("asset_id")
    row = conn.execute("SELECT kind FROM asset WHERE id = ?", (asset_id,)).fetchone()
    if row is None or row["kind"] not in ("image", "frame"):
        raise StudioError(400, "asset_unknown", "Кадр для сцены не найден",
                          {"asset_id": asset_id})
    return "asset", None, asset_id


def _refs_from_tags(cast_by_tag: dict, tags: list[str]) -> list[tuple[str, int, str]]:
    if len(tags) != len(set(tags)):
        raise StudioError(400, "args_invalid", "Тег повторяется в референсах сцены",
                          {"refs": tags})
    out = []
    for ord_, tag in enumerate(tags, start=1):
        member = cast_by_tag.get(tag)
        if member is None:
            raise StudioError(400, "cast_unknown", f"В кастинге нет @{tag}", {"tag": tag})
        out.append((member["id"], ord_, "person"))
    return out


def _write_refs(conn: sqlite3.Connection, scene_id: str, refs: list[tuple[str, int, str]]):
    conn.execute("DELETE FROM scene_ref WHERE scene_id = ?", (scene_id,))
    conn.executemany("INSERT INTO scene_ref (scene_id, cast_id, ord, role) VALUES (?, ?, ?, ?)",
                     [(scene_id, *r) for r in refs])


def lint_project(conn: sqlite3.Connection, project_id: str,
                 scene_ids: list[str] | None = None) -> dict[str, list[dict]]:
    """O9. Findings for every live scene (or the listed ones), keyed by scene id."""
    rows = _live_scenes(conn, project_id)
    project = lint.LintProject(
        scenes=[lint.LintScene(**{k: r[k] for k in (
            "id", "idx", "mode", *TEXT_FIELDS, "requested_s", "frames", "source_frame_kind",
            "source_scene_id")}) for r in rows],
        portrait_phrases={c["tag"]: c["portrait_phrase"] for c in _cast_rows(conn, project_id)})
    wanted = set(scene_ids) if scene_ids is not None else {r["id"] for r in rows}
    unknown = wanted - {r["id"] for r in rows}
    if unknown:
        raise StudioError(404, "scene_not_found", "Сцена не найдена",
                          {"scene_ids": sorted(unknown)})
    return {s.id: lint.lint_scene(s, project) for s in project.scenes if s.id in wanted}


def update_scene(conn: sqlite3.Connection, scene_id: str, *, expected_revision: int,
                 changes: dict) -> dict:
    """O8. Content edits bump `scene.revision` only when the fingerprint changes (И1); the
    project revision is not touched, so editing one scene never stales another's plan (§7)."""
    with db.tx(conn):
        row = _scene_row(conn, scene_id)
        if row["revision"] != expected_revision:
            raise StudioError(409, "revision_conflict",
                              "Сцена изменилась в другом окне — обновите и повторите",
                              {"current": scene_out(conn, row)})
        fields = {name: row[name] for name in STORED_FIELDS}
        for name in ("mode", *TEXT_FIELDS, "seed"):
            if changes.get(name) is not None:
                fields[name] = changes[name]
        if changes.get("requested_s") is not None:
            fields["requested_s"] = changes["requested_s"]
            fields["frames"] = duration.snap_frames(changes["requested_s"])
        live = _live_scenes(conn, row["project_id"])
        if changes.get("source_frame") is not None:
            earlier = [r["id"] for r in live if r["idx"] < row["idx"]]
            kind, src_scene, src_asset = _resolve_source(
                conn, changes["source_frame"], prev_id=earlier[-1] if earlier else None,
                allowed_scene_ids={r["id"] for r in live} - {scene_id})
            fields.update(source_frame_kind=kind, source_scene_id=src_scene,
                          source_frame_asset_id=src_asset)
        old_refs = _refs(conn, scene_id)
        refs = old_refs
        if changes.get("refs") is not None:
            cast_by_tag = {c["tag"]: c for c in _cast_rows(conn, row["project_id"])}
            refs = _refs_from_tags(cast_by_tag, changes["refs"])
        changed = sorted(n for n in STORED_FIELDS if fields[n] != row[n])
        if refs != old_refs:
            changed.append("refs")
        if changed:
            bump = 0 if _fingerprint(fields, refs) == _fingerprint(row, old_refs) else 1
            sets = ", ".join(f"{name} = ?" for name in STORED_FIELDS)
            conn.execute(f"UPDATE scene SET {sets}, revision = revision + ? WHERE id = ?",
                         (*(fields[n] for n in STORED_FIELDS), bump, scene_id))
            if refs != old_refs:
                _write_refs(conn, scene_id, refs)
            events.emit(conn, "scene_updated", project_id=row["project_id"], scene_id=scene_id,
                        payload={"revision": row["revision"] + bump, "fields": changed})
        out = scene_out(conn, _scene_row(conn, scene_id))
    findings = lint_project(conn, row["project_id"], [scene_id])[scene_id]
    # `cascade` (И11) is the list of scenes whose approval this edit revoked; approvals exist
    # from slice S3 on, so in S1 it is always empty.
    return {"scene": out, "cascade": [], "lint": findings}


def replace_scenes(conn: sqlite3.Connection, project_id: str, *, expected_revision: int,
                   scenes: list[dict], event_kind: str = "scenes_replaced",
                   event_payload: dict | None = None,
                   in_tx_hook=None) -> dict:
    """O7 (and O26 through it). Identity is `scene_id`; array order is `idx`; a scene missing
    from the array is soft-deleted; a matched scene keeps its revision unless its fingerprint
    changed (И1). A `prev_last_frame` source without an explicit scene is the previous scene of
    the array, so a reorder that changes it is a content change (§7 «Сопоставление сцен»)."""
    with db.tx(conn):
        prow = _project_row(conn, project_id)
        _check_revision(prow, expected_revision, project_out(prow))
        live = {r["id"]: r for r in _live_scenes(conn, project_id)}
        given = [s.get("scene_id") for s in scenes]
        known = [sid for sid in given if sid is not None]
        if len(known) != len(set(known)):
            raise StudioError(400, "args_invalid", "scene_id повторяется", {"scene_ids": known})
        for sid in known:
            if sid not in live:
                raise StudioError(400, "scene_unknown", "Такой сцены в проекте нет",
                                  {"scene_id": sid})
        final_ids = [sid or ids.new_id("s") for sid in given]
        cast_by_tag = {c["tag"]: c for c in _cast_rows(conn, project_id)}
        diff: dict[str, list[str]] = {"added": [], "unchanged": [], "changed": [], "moved": [],
                                      "deleted": []}
        now = ids.now_iso()
        # Free the live (project_id, idx) slots before writing the new order.
        conn.execute("UPDATE scene SET idx = -1 - idx WHERE project_id = ? AND deleted_at IS NULL",
                     (project_id,))
        for idx, (sid, item) in enumerate(zip(final_ids, scenes)):
            kind, src_scene, src_asset = _resolve_source(
                conn, item["source_frame"], prev_id=final_ids[idx - 1] if idx else None,
                allowed_scene_ids=set(final_ids) - {sid})
            refs = _refs_from_tags(cast_by_tag, item["refs"])
            old = live.get(sid)
            fields = {"mode": item["mode"], **{f: item[f] for f in TEXT_FIELDS},
                      "requested_s": item["requested_s"],
                      "frames": duration.snap_frames(item["requested_s"]),
                      "seed": item["seed"] or (old["seed"] if old else _new_seed()),
                      "source_frame_kind": kind, "source_scene_id": src_scene,
                      "source_frame_asset_id": src_asset}
            names = ", ".join(STORED_FIELDS)
            marks = ", ".join("?" for _ in STORED_FIELDS)
            if old is None:
                conn.execute(f"INSERT INTO scene (id, project_id, idx, created_at, {names}) "
                             f"VALUES (?, ?, ?, ?, {marks})",
                             (sid, project_id, idx, now, *(fields[n] for n in STORED_FIELDS)))
                _write_refs(conn, sid, refs)
                diff["added"].append(sid)
                continue
            old_refs = _refs(conn, sid)
            same = _fingerprint(fields, refs) == _fingerprint(old, old_refs)
            sets = ", ".join(f"{n} = ?" for n in STORED_FIELDS)
            conn.execute(f"UPDATE scene SET idx = ?, {sets}, revision = revision + ? WHERE id = ?",
                         (idx, *(fields[n] for n in STORED_FIELDS), 0 if same else 1, sid))
            if refs != old_refs:
                _write_refs(conn, sid, refs)
            if not same:
                diff["changed"].append(sid)
            elif old["idx"] != idx:
                diff["moved"].append(sid)
            else:
                diff["unchanged"].append(sid)
        for sid in live:
            if sid not in final_ids:
                conn.execute("UPDATE scene SET deleted_at = ? WHERE id = ?", (now, sid))
                diff["deleted"].append(sid)
        conn.execute("UPDATE project SET revision = revision + 1 WHERE id = ?", (project_id,))
        if in_tx_hook is not None:
            in_tx_hook(conn)
        events.emit(conn, event_kind, project_id=project_id,
                    payload={"diff": diff, **(event_payload or {})})
        out = [scene_out(conn, r) for r in _live_scenes(conn, project_id)]
        project = project_out(_project_row(conn, project_id))
    return {"project": project, "scenes": out, "diff": diff,
            "lint": lint_project(conn, project_id)}
```

```markdown
You are the scenarist of a short video made of consecutive scenes, each scene rendered by the
MiniMax H3 video model as its own 3–15 second clip. Scene N+1 starts from the last frame of
scene N, so the end of one scene is the beginning of the next.

Input: a JSON object with
- `idea` — what the owner wants, usually in Russian;
- `scenes_count` — exactly how many scenes to write;
- `frame_format` — "16:9" or "9:16";
- `style_block` — visual style to respect (may be empty);
- `cast` — characters: `tag`, `description_en`, `portrait_phrase`.

Answer with one JSON object `{"scenes": [...]}` holding exactly `scenes_count` scenes, in play

  where the camera is. Do not repeat the character's portrait: the code pastes it in. Never
  name an absent character, even in a negation. Never write "@tag" or "mode:".
- `performance` — the acting: the inner state at the start, how and when it changes, the face,
  the gaze, the hands, small movements. A scene without a change of state reads as a dead face.
- `sound` — what sounds, described physically: the material and the contact ("bare heels on

  does not sound only after what does.
- `music` — non-diegetic music: instruments, tempo, dynamics, or "none".
- `state_in` — one sentence: the frame at the first moment of the scene.
- `state_out` — one sentence: the frame at the last moment; the next scene starts from it.
- `cast_tags` — tags from `cast` who are on screen in this scene.
- `requested_s` — length in seconds, 3 to 15; 8 is a good default.

Do not count above three in the action: say "several" instead of a number.
```

```python
"""«Сценарист» (spec §9.1): idea -> scenes. The model writes the words; the code does the
arithmetic — number of scenes, lengths, modes and sources, the verbatim portrait phrase."""
from __future__ import annotations

import hashlib
import json
from pathlib import Path

from h3_48gb.studio.duration import MAX_SECONDS, MIN_SECONDS
from h3_48gb.studio.errors import StudioError
from h3_48gb.studio.llm import Llm

PROMPT = Path(__file__).parent / "prompts" / "scenarist.md"
MAX_SCENES = 12

_STR = {"type": "string"}
STUDIO_SCENES_SCHEMA = {
    "name": "studio_scenes",
    "schema": {
        "type": "object",
        "properties": {
            "scenes": {
                "type": "array",
                "items": {
                    "type": "object",
                    "properties": {
                        "action": _STR, "performance": _STR, "sound": _STR, "music": _STR,
                        "state_in": _STR, "state_out": _STR,
                        "cast_tags": {"type": "array", "items": _STR},
                        "requested_s": {"type": "number", "minimum": MIN_SECONDS,
                                        "maximum": MAX_SECONDS},
                    },
                    "required": ["action", "performance", "sound", "music", "state_in",
                                 "state_out", "cast_tags", "requested_s"],
                    "additionalProperties": False,
                },
            },
        },
        "required": ["scenes"],
        "additionalProperties": False,
    },
}
RETRY_REMINDER = ("Ответ строго одним JSON-объектом {\"scenes\": [...]} по схеме, без другого "
                  "текста.")


def prompt_version() -> str:
    return hashlib.sha256(PROMPT.read_bytes()).hexdigest()[:12]


def _with_portraits(action: str, phrases: list[str]) -> str:
    missing = [p for p in phrases if p and p not in action]
    if not missing:
        return action
    return ". ".join(missing) + ". " + action


def propose(llm: Llm, *, idea_text: str, scenes_count: int, frame_format: str,
            style_block: str, cast: list[dict]) -> tuple[list[dict], dict]:
    """Return (scenes in the O7 input shape, llm_json for the proposal row).

    `cast` items: `{"tag", "description_en", "portrait_phrase", "has_image"}`."""
    user = {"idea": idea_text, "scenes_count": scenes_count, "frame_format": frame_format,
            "style_block": style_block,
            "cast": [{k: c[k] for k in ("tag", "description_en", "portrait_phrase")}
                     for c in cast]}
    messages = [{"role": "system", "content": PROMPT.read_text(encoding="utf-8")},
                {"role": "user", "content": json.dumps(user, ensure_ascii=False)}]
    raw = llm.json_turn(messages, STUDIO_SCENES_SCHEMA, RETRY_REMINDER)
    got = raw["scenes"]
    if len(got) != scenes_count:
        raise StudioError(502, "llm_failed",
                          f"Сценарист вернул {len(got)} сцен вместо {scenes_count}",
                          {"got": len(got), "wanted": scenes_count})
    by_tag = {c["tag"]: c for c in cast}
    scenes = []
    for i, s in enumerate(got):
        tags = [t.lstrip("@") for t in s["cast_tags"] if t.lstrip("@") in by_tag]
        with_image = [t for t in tags if by_tag[t]["has_image"]]
        if i == 0:
            mode = "refs" if with_image else "from_frame"
            source = {"kind": "none", "scene_id": None, "asset_id": None}
            refs = with_image if mode == "refs" else []
        else:
            mode = "from_frame"
            source = {"kind": "prev_last_frame", "scene_id": None, "asset_id": None}
            refs = []
        requested = min(max(float(s["requested_s"]), MIN_SECONDS), MAX_SECONDS)
        scenes.append({
            "scene_id": None, "mode": mode,
            "action_text": _with_portraits(s["action"].strip(),
                                           [by_tag[t]["portrait_phrase"] for t in tags]),
            "performance_text": s["performance"].strip(), "sound_text": s["sound"].strip(),
            "music_text": s["music"].strip(), "state_in_text": s["state_in"].strip(),
            "state_out_text": s["state_out"].strip(), "requested_s": requested, "seed": None,
            "source_frame": source, "refs": refs,
        })
    llm_json = {"provider": llm.label, "prompt_version": prompt_version(), "raw": raw}
    return scenes, llm_json
```

```python
def propose_scenes(conn: sqlite3.Connection, project_id: str, *, llm: Llm,
                   idea_text: str, scenes_count: int) -> dict:
    """O25. Saved as a `proposal`, not applied. The LLM call runs outside any transaction."""
    prow = _project_row(conn, project_id)
    cast = []
    for c in _cast_rows(conn, project_id):
        has_image = conn.execute("SELECT 1 FROM cast_asset WHERE cast_id = ? AND role = 'image'",
                                 (c["id"],)).fetchone() is not None
        cast.append({"tag": c["tag"], "description_en": c["description_en"],
                     "portrait_phrase": c["portrait_phrase"], "has_image": has_image})
    scenes, llm_json = scenarist.propose(llm, idea_text=idea_text, scenes_count=scenes_count,
                                         frame_format=prow["frame_format"],
                                         style_block=prow["style_block"], cast=cast)
    proposal_id = ids.new_id("r")
    with db.tx(conn):
        conn.execute(
            "INSERT INTO proposal (id, project_id, project_revision, idea_text, scenes_json, "
            "llm_json, created_at) VALUES (?, ?, ?, ?, ?, ?, ?)",
            (proposal_id, project_id, prow["revision"], idea_text,
             json.dumps(scenes, ensure_ascii=False), json.dumps(llm_json, ensure_ascii=False),
             ids.now_iso()))
        events.emit(conn, "proposal_created", project_id=project_id,
                    payload={"proposal_id": proposal_id, "scenes": len(scenes)})
    return {"proposal_id": proposal_id, "scenes": scenes}


def apply_proposal(conn: sqlite3.Connection, project_id: str, *, proposal_id: str,
                   expected_revision: int) -> dict:
    """O26: the proposal's scenes replace the project's set through the O7 path."""
    row = conn.execute("SELECT * FROM proposal WHERE id = ? AND project_id = ?",
                       (proposal_id, project_id)).fetchone()
    if row is None:
        raise StudioError(404, "proposal_not_found", "Предложение не найдено",
                          {"proposal_id": proposal_id})
    if row["applied_at"] is not None:
        raise StudioError(409, "proposal_already_applied", "Это предложение уже применено",
                          {"proposal_id": proposal_id, "applied_at": row["applied_at"]})

    def mark_applied(c):
        # Two clicks racing past the check above cannot both land: the second one's
        # expected_revision is stale by then and replace_scenes refuses it with 409.
        c.execute("UPDATE proposal SET applied_at = ? WHERE id = ?", (ids.now_iso(), proposal_id))

    return replace_scenes(conn, project_id, expected_revision=expected_revision,
                          scenes=json.loads(row["scenes_json"]), event_kind="proposal_applied",
                          event_payload={"proposal_id": proposal_id}, in_tx_hook=mark_applied)
```

```tsx
export function SceneCard({ scene, findings, onSaved, onConflict, onDelete }: {
  scene: Scene;
  findings: Finding[];
  onSaved: (r: SceneResult) => void;
  onConflict: () => void;
  onDelete: () => void;
}) {
  const [draft, setDraft] = useState(() => ({
    ...Object.fromEntries(FIELDS.map(([f]) => [f, scene[f]])) as Record<TextField, string>,
    requested_s: String(scene.requested_s),
    seed: String(scene.seed),
  }));
  const [error, setError] = useState<string | null>(null);

  function changes(): Partial<ScenePatch> {
    const out: Partial<ScenePatch> = {};
    for (const [f] of FIELDS) if (draft[f] !== scene[f]) out[f] = draft[f];
    if (Number(draft.requested_s) !== scene.requested_s) out.requested_s = Number(draft.requested_s);
    if (Number(draft.seed) !== scene.seed) out.seed = Number(draft.seed);
    return out;
  }
  const dirty = Object.keys(changes()).length > 0;

  async function save() {
    setError(null);
    try {
      onSaved(await api<SceneResult>("PATCH", `/scenes/${scene.id}`, { expected_revision: scene.revision, ...changes() }));
    } catch (err) {
      if (err instanceof ApiError && err.code === "revision_conflict") {
        setError("Сцена изменилась в другом окне — показана свежая версия, ваши правки не сохранены");
        onConflict();
      } else {
        setError(err instanceof ApiError ? err.message : "Сервер не ответил");
      }
    }
  }
```
