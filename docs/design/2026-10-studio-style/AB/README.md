# Направление AB — гибрид (дизайн-система студии)

Решение владельца 21.10.2026: «как база A, а оформление кадров, расположение и размеры виджетов B».
Файл: `AB/index.html` (`#projects`, `#scene`, `?theme=light|dark`). Tailwind v4 browser build, токены — CSS-переменные.

## Взято из A (язык)
Палитра, кобальтовый акцент, шрифты, линии 1px, моно-метки (eyebrow), маршрут из 6 сегментов (3px) с моно-подписями,
крупные цифры сид/шаги/длительность (Inter Tight 30px), шапка 56px с плашкой видеокарты и переключателем темы, радиусы 4/6/10, без теней.

## Взято из B (компоновка)
- Проекты: 2 колонки (gap 32px), крупное превью 16:9 на всю ширину карточки, название 24px.
- Редактор: сетка `1.3fr / 1fr` — кадр-герой слева, панель полей справа (рамка 1px), лента дублей под кадром.
- Оформление кадров: метки поверх кадра «Первый кадр» (тёмное стекло) / «из сцены 1» (кобальт) / «16:9 · 8 с»; на карточках
  проектов — «№ 01», число сцен, длительность, градиент снизу, прогресс считающегося финала.
- Лента дублей — плёнка с перфорацией, перекрашена под A: чёрная ink-подложка, перфорация цветом фона, дубль-выбор в рамке кобальта.
  Кнопки «Годится / Пересъёмка» — друг под другом на всю ширину дубля, высота 36px (на 1440 дубль ≈ 220px — рядом было бы тесно).

- Шрифты: Inter Tight 500/600/700 (заголовки, цифры, letter-spacing −.025em), Inter 400–600 (текст, 14px/1.45), JetBrains Mono 400/500 (метки 11px, caps, .06em).
- Радиусы: 4 (сегмент), 6 (кнопки, поля, дубли), 10 (карточки, панель, кадр-герой, плёнка), 999 (чипы).
- Тени: нет; иерархия — линии 1px; hover карточки — рамка цвета ink.
- Размеры: кнопка 32px, крупная 44px (главная на десктопе 48px), поля 13.5px, контейнер max 1360px, поля страницы 32px (16px на телефоне).
- Телефон 390: одна колонка, дубли друг под другом, главная кнопка закреплена внизу; textarea растут по тексту (`field-sizing:content`).

## Проверено
Переполнение: scrollWidth на 390 = 390 для обоих экранов. Снимки: `shots/` (6 штук).

## Спорно
- `field-sizing:content` не работает в старых Safari/Firefox — там поля останутся фиксированной высоты (rows=3).
- Перфорация плёнки красится цветом фона страницы — при смене фона блока нужно менять и её.
