# Направление C — «Воздух»

Файл: `index.html` (адреса `#projects`, `#scene`, тема `?theme=light|dark`). Шрифт Onest (400–700, кириллица). Tailwind v4 browser 4.1.13, токены в `@theme`, значения цветов — CSS-переменные `--c-*` по теме.

| ink / ink2 / ink3 | #171a3a / #4a4f78 / #5d6288 | #eef0ff / #b9bde0 / #a2a7d0 |

Радиусы: карточки 1.75rem, поля 1rem, кнопки и чипы — полная капсула, превью 1rem–1.5rem. Тени: `0 10px 40px -12px rgba(80,70,180,.25)` (тёмная: чёрная .6); у главной кнопки цветная `0 10px 26px -10px accent`.

## Контраст (расчёт WCAG, фон — самая тёмная точка подложки)
Светлая: ink2/белый 7.8, ink3/лавандовый 4.8, акцент/белый 6.3, белый/кнопка 6.3, warn 5.8, ok после правки около 5.5. Тёмная: ink3 7.1, текст кнопки 6+, ok 6.9, warn 7.9; акцент на плашке после осветления до #a396ff выше 4.5 (пересчитан только оценочно).

## Что удалось
Стеклянная плавающая шапка-капсула, пастельные пятна лаванда→небо, маршрут из 6 шагов с точками и подписями, плашка видеокарты (на 390 — отдельной строкой под шапкой), редактор в две колонки (форма + лента дублей), на 390 одна колонка и закреплённая снизу главная кнопка. Горизонтального переполнения нет: scrollWidth 1440/390 при всех снимках.

## Спорно
- Контраст замерялся по оценочным цветам подложки, а не по пикселям снимка; плашки на градиенте могут давать ±0.3.
- backdrop-blur почти не виден на светлом фоне без ярких пятен под панелью; эффект «стекла» сильнее в тёмной теме.
- Во всех превью один лесной кадр с героиней — карточки визуально похожи (ограничение набора файлов).
- На снимке 390 страница снята высотой в весь документ, чтобы закреплённая кнопка оказалась внизу, как на телефоне.
- Прямые «Идея→…» подписи под маршрутом на 390 скрыты (остались только точки с title).
