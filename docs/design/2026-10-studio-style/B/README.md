Файл: `index.html` (Tailwind v4 browser 4.1.13, Manrope с кириллицей). Адреса `#projects`, `#scene`; тема `?theme=light|dark`
(по умолчанию светлая, `prefers-color-scheme` не используется). Снимки: `shots/`.

В тёмной теме тени чёрные, плотнее.

## Что удалось
- Медиа главное: превью проектов 16:9 на всю ширину карточки (2 колонки на 1440), герой сцены — крупный первый кадр с метками «Первый кадр» / «из сцены 1».
- Лента дублей — тёмная «плёнка» с перфорацией сверху и снизу, выбранный дубль обведён бирюзой; в обеих темах плёнка тёмная.
- Маршрут из 6 шагов — шесть сегментов с заливкой текущего шага по проценту; на 390 подписи заменены строкой «Шаг N из 6 · …».
- На 390 одна колонка, кнопка «Снять эскиз» закреплена снизу. Горизонтального переполнения нет: scrollWidth = 390 (проекты и сцена), на 1440 = 1440.
- Поля используют `field-sizing: content`, текст не обрезается.

## Спорно
- Все превью — кадры одного леса и одной героини (других файлов брифом не дано), поэтому карточки визуально близки; в проекте «Венок на воде» стоит кадр с улыбкой, что не вяжется с названием.
- Дубли 1–3 взяты из разных файлов (draft-last, krea2-s2, krea2-s3) — это имитация, не реальные дубли сцены 2.
- Тёмная плёнка в тёмной теме почти сливается с фоном: держится на перфорации и рамке выбранного дубля.
- Кнопки «Годится / Пересъёмка» на 1440 в узкой ленте тесные (три дубля в ряд); можно уменьшить текст или оставить иконки.
- Tailwind CDN без SRI (по брифу), шрифты и скрипт требуют сети.
- Снимки 390 сняты с высотой окна = высоте страницы, чтобы закреплённая кнопка легла внизу.
