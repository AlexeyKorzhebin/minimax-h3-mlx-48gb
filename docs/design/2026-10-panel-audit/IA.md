# Информационная архитектура новой панели (предложение)

Основа: `AUDIT.md` (инвентарь и проблемы), спека порта `docs/superpowers/specs/2026-10-06-panel-on-alex-neuro-design.md` §3.3.13–14, §3.5, §4, §10. Инвариант спеки: всё поведение — в JSON-API, интерфейс только вызывает его; эта IA ничего не требует от бэкенда сверх уже описанного (отмечено «нужен API» там, где это не так).

## 1. Принципы

1. **Разные вещи — разные места.** Проекты (долгая работа), Референсы (общий словарь), Очередь (что сейчас считается) и Настройки (редкое) — четыре верхних раздела вместо одной страницы.
2. **Проект — страница с адресом, не модалка.** `#/projects/<id>/<шаг>`; можно дать ссылку, держать открытыми две вкладки.
3. **Маршрут проекта виден всегда:** Сценарий → Сцены → Апскейл → Сборка (для клипа под трек перед «Сценами» ещё «Трек» и «Сюжет», см. §3). Один шаг — один экран; одно главное действие на шаг.
4. **Состояние железа — отдельный постоянный элемент (плашка GPU), не часть навигации и не часть очереди.** Она на любом экране; очередь и проект только ссылаются на неё причиной ожидания.
5. **Редкое — глубже.** Параметры модели, сид, тег, пути, провайдеры, Finder — за «Параметры», «⋯» и «Настройками».
6. **Подтверждения — встроенные, у кнопки,** не `window.confirm`; необратимое объясняет последствие («пересчитает эту и 12 следующих сцен»).

## 2. Карта навигации

```
[h3]  Проекты · Референсы · Очередь · Настройки          [ плашка GPU ]  [тема]
        │          │          │          └ LLM, Qwen, модель по умолчанию, пути, промпты, тема
        │          │          └ задачи по порядку; быстрый прогон; журнал
        │          └ библиотека карточек @тег
        └ список → проект → шаги маршрута
```

На 390 px: нижняя панель «Проекты / Референсы / Очередь / Ещё(=Настройки)», плашка GPU — сжатый чип в верхней полосе (точка + «Освободить»), разворачивается в шторку.

## 3. Проект: шаги маршрута по видам

| Kind | Шаги |
|---|---|
| video (ролик) | Сценарий → Сцены → [Апскейл] → Сборка |
| clip (клип под трек) | Трек → Сценарий → Сюжет → Сцены → [Апскейл] → Сборка (в порядке гейтов нынешней панели; «Сюжет» — это раскадровка 16–40 сцен) |
| song (песня; вне v1, но не ломаем) | Сценарий → Трек |

Апскейл — этап по галочке проекта «Апскейл LTX после сцен» (одна сила на весь клип, спека §2). Шаг-«мастер» показывает: заголовок шага, статус, один главный CTA («Утвердить», «Поставить N сцен в очередь», «Собрать»), назад/вперёд. Утверждённые шаги сворачиваются в одну строку со ссылкой «открыть».

Внутри шага «Сцены»: список сцен (статус, миниатюра, время на оси) → выбранная сцена: плеер, текст с `@`-тегами, **полоска миниатюр уходящих в H3 картинок «N из максимума»**, «Пересчитать сцену» (с объяснением каскада), «Чат по этой сцене». Справа/ниже — «Референсы проекта» (подключить/отключить, версия, «обновить до vN»).

## 4. Куда переезжает каждый элемент старого интерфейса

| Было (зона / элемент) | Станет |
|---|---|
| Шапка: статус работника, очереди, LLM, строка прогона | Плашка GPU + мини-статус очереди «идёт: сцена 14 · 62 %» рядом с ней; «работник» перестаёт быть отдельным показанием (пишется причиной в очереди); LLM — в плашке как «Qwen» |
| Шапка: хост, часы, «обновлено в», деления | Подвал страницы / Настройки → «О панели»; деления — в карточке идущей задачи |
| Шапка: «Тема» | Настройки (и иконка ◐ в шапке) |
| Зона 1 «Сочинение» (форма одиночного прогона) | Очередь → «+ Быстрый прогон» (шторка/страница): промпт, разрешение, длительность, режим; «Параметры» (раскрывашка): сид, тег, кадры, настройки модели, каталог |
| «Библиотека промптов», «Сохранить в файл» | Настройки → Промпты (служебная страница) и «Загрузить из файла» в быстром прогоне |
| «Новый через диалог» | Проекты → «+ Новый проект» (выбор вида: Ролик / Клип под трек), затем чат внутри проекта; «Быстрый прогон» тоже может открыть чат |
| Зона 2 «Очередь»: старт/пауза | Очередь → верх справа «⏸ Пауза / ▶ Начать» |
| «Идёт»: превью TAE, 5 цифр, деления | Очередь → карточка «Идёт сейчас» (название проекта+сцены, шаг n/N, ≈время, превью) |
| Плашка «выгрузить и начать» / «пусть ждёт» | Над очередью — баннер причины ожидания (Qwen держит карту / чужое на GPU / замок) с кнопкой «Выгрузить Qwen и начать» (спека §3.3.13) |
| Ждущие: Обсудить / Править / Наверх / Копия / Удалить | Строка = смысл («Сцена 14 · Колыбельная — ночь 5»); основные: «↑» и «✕» (с отменой на 5 с вместо confirm), остальное — «⋯» |
| Зона 3 «Проекты» | Раздел «Проекты»: карточки/таблица с маршрутом-индикатором и «следующим шагом» |
| Зона 4 «Готово» | В проекте: шаг «Сборка» (финальный ролик) + раздел «Результаты» в списке проекта; одиночные прогоны — Очередь → «Журнал/Готово» с фильтром по дню |
| «Показать в Finder» | «⋯» на результате (на alex-neuro — «Скопировать путь»/«Скачать») |
| Модалка проекта, этап «Сценарий» | Шаг 1 «Сценарий» |
| Этап «Трек» | Шаг «Трек» (плеер, «Утвердить трек», «Пересчитать» в «⋯» + сид) |
| Этап «Сюжет» (пояснения, провайдер, «Проверить», «Сгенерировать», «Без LLM», «Сохранить», «Утвердить») | Шаг «Сюжет»: главный CTA «Сгенерировать сюжет», остальное в «⋯» и Настройки → LLM; автосохранение без отдельной «Сохранить»; редактор одной сцены, а не 40 полей разом (список слева) |
| Этап «Сцены» + «пересчитать» на каждой | Шаг «Сцены» (см. §3), «Пересчитать» у выбранной сцены |
| Этап «Сборка» | Шаг «Сборка» |
| Модалка чата | Панель чата внутри проекта/сцены (боковая) + общий чат из «+ Новый проект»; шапка: только «Сделать проектом»/«Применить»; провайдер и длительность — в «⋯» |
| «Сделать проектом» (радио Music3/mp3) | «+ Новый проект» → выбор вида → для клипа «трек: загрузить mp3 / сгенерировать» |
| Селектор провайдера внутри чата и сюжета | Один глобальный выбор в Настройки → LLM (+ быстрый выбор в чате) |
| **Новое:** плашка GPU | Шапка, всегда. Содержимое: статус (считает: что / свободна / чужое: имя+pid+память / Qwen держит), память, температура (порог 84), замок, Qwen: «выгружен нами в hh:mm» |
| **Новое:** «Освободить карту» | В плашке (кнопка, неактивна при чужом/замке чужого) и в карточке «Видеокарта» очереди; рядом — обратный отсчёт автоотдачи «через 15 мин после пустой очереди» |
| **Новое:** кнопки Qwen | Очередь/плашка: «Выгрузить Qwen и начать» (баннер ожидания), «Вернуть Qwen» (показывается только если Qwen был запущен до выгрузки) |
| **Новое:** библиотека референсов | Раздел «Референсы» (сетка/полки, фильтр по типу, поиск по тегу, перетаскивание, карточка: теги/тип/описание/версии, «где используется», «обновить до vN») |
| **Новое:** референсы проекта | Боковой блок шага «Сцены» и вкладка проекта «Референсы» |
| **Новое:** `@`-теги в тексте сцены | Редактор сцены: подсказка по `@` с превью, подсветка ошибки до постановки в очередь |
| **Новое:** галочка этапа «Апскейл» | Настройки маршрута проекта (шаг «Сцены», блок «Дальше по маршруту») + отдельный шаг «Апскейл» со статусом пачки |

## 5. Плашка GPU: поведение

- Состояния (из `GET /status` диспетчера, спека §3.4): `считает` (наш H3/LTX, что именно), `свободна` (движки погашены), `чужое` (имя+pid+память, мы не гасим), `Qwen держит`, `замок занят`, `поднимается` (starting) и `ошибка` (+ путь к логу).
- Свёрнутый вид: точка-индикатор + 1 фраза + кнопка. Раскрытый (клик или страница «Очередь»): память-шкала, температура, замок, Qwen, автоотдача, две кнопки.
- «Освободить карту» → `POST /release`; подтверждение не нужно, если очередь пуста, иначе встроенное «Очередь не пуста: расчёт остановится».
- Кнопки Qwen показываются по состоянию, не всегда (спека: «вернуть» только если Qwen был запущен до выгрузки).
- Ожидание карты — не ошибка: в очереди у задачи статус «ждёт карту: ComfyUI Krea2 (pid 4412)», у проекта — та же причина.
- Нужен API: опрос `/status` панелью уже предусмотрен §3.3.13; новых маршрутов не требуется.

## 6. Что вынесено в «Настройки»

LLM (провайдер, «Проверить»), Qwen (статус, выгрузить/вернуть), модель по умолчанию (чекпойнт, LoRA, шаги, AdaLN), каталоги, промпты, автоотдача (`H3_IDLE_RELEASE_MIN`), тема, о панели (хост, версия).

## 7. Допущения и открытые вопросы

- Допущено: максимум картинок на сцену (`H3_MAX_REF_IMAGES`) в макетах равен 4 — реальное значение определит проба (спека §6).
- Допущено: одиночный «Быстрый прогон» остаётся нужным (его частоту знает только владелец; метрик нет). Если не нужен — зона 1 исчезает целиком.
- Допущено: «Освободить карту» неактивна при чужом процессе (мы чужое не гасим).
- Открыто: нужна ли пользователю страница «Результаты» отдельно от проектов (предлагается: нет; финал — шаг «Сборка» проекта).
- Открыто: песни (kind=song) вне v1 — оставлены в списке проектов без изменений.
- Открыто: на alex-neuro «Показать в Finder» теряет смысл — заменить на скачивание/копирование пути; решает волна 2.
