# Вариант A, волна 2: недостающие экраны

Добивка макета A («мастер», подтверждён владельцем 09.10) по `docs/superpowers/specs/2026-10-09-panel-wave2-CJM.md` §4.
Визуальный язык, токены и компоненты взяты из `../variant-a/index.html`.

**Как открыть.** Через любой http-сервер из папки `mockups/`, например `python3 -m http.server`, затем
`variant-a-wave2/index.html`. Файл самодостаточный, внешних зависимостей нет (по file:// не проверялся — Playwright его блокирует).
- Адреса: `#toc` (оглавление), `#projects`, `#s1`…`#s15`, `#s5/1` (редактор сцены 1 в режиме «Референсы»).
- Тема: `?theme=dark|light`. `?freeze=1` останавливает отсчёт «Отмена 5 с» для снимков.
- Режим в редакторе (`#s5`) переключается кликом, поля перестраиваются под режим.

**Пример.** Ролик «Венок на воде», 4 сцены по 8 с, 16:9, 896×512. Сцена 1 — «Референсы» (`@slavicgirl`, `@bereg`, `@venok`, 6 из 6 картинок, аудио `@reka-zvuk` 12 с). Сцены 2–4 — «От кадра».

**Снимки:** `shots/NN-name-1440.png` и `-390.png`, светлая тема. Сняты Playwright в headless Chromium.
- Длинные экраны сняты целиком, окно растянуто по высоте документа.
- Чат (03) снят в размере окна. На 390 это шторка.
- Переполнение по горизонтали проверено скриптом на всех 15 экранах в обеих ширинах: ни один элемент не выходит за ширину окна. Детектор проверен мутацией: блок шириной 600 px на 390 он поймал.

## Что осталось спорным

1. **Шаги маршрута.** Здесь их 6: Идея → Кастинг → Сценарий → Эскизы → Финал → Сборка. В IA §3 их 4: Сценарий → Сцены → [Апскейл] → Сборка. Апскейл свёрнут в «Сборку» галочкой. Проверка ввода (экран 6) — вход в шаг «Эскизы», отдельного шага у неё нет. Нужно согласие владельца.
2. **«Очередь» не обновлена.** В variant-a она про клип на 40 сцен, без вариантов ref2va/fl2va и без смен в плане. Плашка и состояния нарисованы (экраны 11, 12), а сама страница очереди волны 2 — нет.
3. **Оценки времени эскизов** (≈ 4,5 и ≈ 6,5 мин на 8 с, ≈ 13 мин на каскад, ≈ 5 мин на одну сцену) — экстраполяция. Замерено только 3 с при 20 шагах. Источник счётчика шагов (Н7) не выбран, поэтому есть состояние «шаг неизвестен».
4. **Поле «Звук действий»** вынесено в сцену отдельно от «Что в кадре». Решение владельца требует только, чтобы чат описывал звук через материал и походку. Отдельное поле в редакторе — моё допущение.
5. **Плотность на 390.** Переключатель шести режимов переносится в две строки, а длинная сцена в редакторе занимает около 2,6 тыс. px. На живом телефоне это не проверялось, снимки сделаны в headless Chromium.
