# Макеты волны 2 (статические, самодостаточные)

Открывать `variant-{a,b,c}/index.html` напрямую (file://). Экраны: `#projects` `#scenes` `#library` `#queue`. Параметры: `?theme=light|dark`, `?gpu=run|idle|foreign|qwen` (состояние плашки GPU). Скриншоты — в `screens/` (`<вариант>-<экран>-<тема>-<ширина>.png`, ширины 1440 и 390).

- A — пошаговый маршрут («мастер»): один шаг проекта на экране, степпер сверху.
- B — рабочий стол: три панели + постоянная строка состояния GPU внизу.
- C — монтажная: таймлайн с дорожками Трек/Сцены/Апскейл/Сборка; очередь — дорожка видеокарты.

Допущения: данные вымышленные (по мотивам «Колыбельная — ночь 5»), лимит картинок на сцену = 4, шрифты системные (без сети), иконки — символы Unicode.
